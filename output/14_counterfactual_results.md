# N. Counterfactual Results — 개입 전후 비교 (Baseline vs Intervention)

> 출력 N | Quiet Move가 없는 세계(Baseline)와 있는 세계(Intervention)를 같은 페르소나로 비교(스펙 §31).
> 비교 축: 행동 단계 / 시간 / 반복 횟수 / 확인 횟수 / 앱 전환 / 기억 부담 / 감정 소모 / 불안 / 갈등 / 실수 가능성 / 비용 / 피로 / 타인 추가 작업.

## N-1. QM-01 (준비물 사진) — P07·P01

| 축 | Baseline | Intervention | 변화 |
|---|---|---|---|

| 불안 | 아침마다 재확인(확인 없이 1주 불가) | 2초 확인 후 종료 | 해소 |

| 축 | Baseline | Intervention | 변화 |

| 불안/갈등 | 진폭 상승(폭발 1건) | 진폭 하락(폭발 0건) | 갈등 4→2 |

## N-3. QM-03 (정보 2채널·토요일 회의) — P09·P05

| 축 | Baseline | Intervention | 변화 |
|---|---|---|---|
| 행동 단계 | 순회(3채널)→스크랩→질문 | 수집(2채널)+메모→주1회 회의 | 단계 3→2 |
| 시간 | 주 315분(45분/일) | 주 ~105분(15분×5+회의60) | **-67%** |
| 반복/확인 횟수 | 정보 체크 45→15회/일 | 6회/일 | -60% |
| 앱 전환 | 3채널+앱 다수 | 2채널 | 감소 |
| 감정 소모(E) | 0.9(최대) | 0.5 | **-45%** |
| 불안 | 정보 그만두면 불안(회피 소용) | 토요일에 알게 된다는 구조적 안심 | 구조화 |
| 갈등 | 문진→회피→거짓 보고 | 문진 폐지(경험 질문) | 해소 |
| 실수 가능성 | 정보 과잉으로 인한 잘못된 결정 위험 | 신뢰 소스 제한(결정 질 향상 기대) | 감소 |
| 피로 | 엄마 소진+아들 수치 | 낮음 | 감소 |
| 타인 추가 작업 | 학원·카페 문의 수시 | 주 1회 정리 | 감소 |

**판정**: 정보량은 줄었지만 **결정 품질(2채널)과 가족 관계(온기)가 동시에 상승**하는 가장 희귀한 개입.

## N-5. QM-05 (탈락 카드 24시간) — P11

| 축 | Baseline | Intervention |
|---|---|---|
| 후 행동 | 탈락 후 3일 지원 회피 | 2~3일 내 다음 지원 |
| 감정 소모(E) | 0.8(전체 자책) | 0.5(부분 귀인) |
| 자기평가 | -0.9 파동 | -0.4~-0.5 파동(제한) |
| 기억 저장 유형 | '자기평가 정보'(잔류 0.7) | '사건 정보'(잔류 0.4) |

| 피로 | 심리 소진+알바 부담 | 관리 가능 |

**판정**: 시간 비용(10분) 대비 **자기평가 보호 효과**가 큰 개입. 단, 3문장 카드 습관 형성에 2~3회 반복 필요(기대).
