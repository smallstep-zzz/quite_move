# M. Minimal Products — Quiet Move를 구현하는 가장 작은 제품

> 출력 M | 각 Quiet Move를 "가장 작은 것"으로 구현했을 때의 제품 명세.
> 원칙(스펙 §30): 새 생활방식을 만들지 않는다. 기존 도구·앱·습관 위에서 동작하는 **템플릿/카드/기능 1개** 수준이다.
>
> ⚠️ 대부분의 QM은 **신규 앱이 필요 없다.** 최소 제품은 "종이 1장" 또는 "기존 앱의 필드 1개"다.

---

## MP-01 — "준비물 사진 한 장" (QM-01)

| 항목 | 내용 |
|---|---|
| 형태 | **가족 채팅방 고정 공지 1줄 + A5 카드 1장(부엌 부착)** |
| 흐름 | 전날 밤: 아이가 준비물 넣음 → 카드의 체크란 훑음 → 가방 사진 1장 → 톡에 업로드 → 아침: 엄마가 2초 확인 |
| 동작 조건 | 폰 카메라, 가족 채팅방(기존) — 신규 앱 0 |
| 측정 | 주간 사진 업로드 횟수 / 누락 건수(주 0회 목표) — 채팅방 검색으로 집계 |
| 비용 | 인쇄 2장+고정. 0원 |
| 확장 단계 | (1단계) 카드·공지 → (2단계) 알림장 앱에 '아이 첨부 사진' 필드 활성화(신규 코딩 1개) |

> **제품보다 행동 설계가 본체** — 카드가 없어도 되지만, 카드는 3일간의 행동 강화를 위한 기억 보조물이다.

## MP-02 — "주간 스크린 리뷰 15분" (QM-02)

| 항목 | 내용 |
|---|---|
| 형태 | **A4 1장 '월간 스크린 리뷰 시트'(가족 1부)** + 고정 시간(일요일 저녁) |
| 흐름 | 일요일 18:00 → 둘이 폰 OS 화면 공유 → 시트에 앱별 합계 기입 → 규칙 1개만 협상 → 다음 주 목표 1줄 |
| 동작 조건 | OS 스크린타임(기본 제공), 프린트 시트 — 신규 앱 0 |
| 측정 | 주간 합계 대비 목표(예: 게임 14→12h), 갈등 횟수(방문 slam 0회) |
| 비용 | 인쇄 1장. 0원 |
| 확장 단계 | (2단계) '가족 스크린 리포트' 기능 — 기존 자녀보호 앱의 '리뷰 미팅 화면' |

## MP-03 — "입시 정보 2채널 + 토요일 회의 시트" (QM-03)

| 항목 | 내용 |
|---|---|
| 형태 | **'입시 가족 회의 시트'(A4, 주 1장)** — 좌측: 신뢰 채널 2개 목록 / 중앙: 이번 주 수집 메모 5줄 / 하단: 가족 결정 1개 |
| 흐름 | 월~금 15분 수집(2채널만) → 메모 → 토요일 1h 회의에서 시트 채우며 결정 → 평일은 '문진 금지' |
| 동작 조건 | 기존 카페·뉴스(신뢰 소스), 종이 시트 — 신규 앱 0 |
| 측정 | 수집 시간(45→15분), 엄마 감정 비용(E 0.9→0.5), 아들 거짓 보고 0회 |
| 비용 | 인쇄 1장/주. 0원 |
| 확장 단계 | (2단계) 기존 '입시 일정 어플'에 '가족 회의' 탭 → 채널 2개 + 메모 연동 |

## MP-04 — "하루 1문장 질문 카드" (QM-04)

| 항목 | 내용 |
|---|---|
| 형태 | **질문 카드 10장(물리) + '응답 맞장구' 예시 뒷면** |
| 흐름 | 저녁 식사 중 카드 1장 → 질문 1개 → 응답 3~5문장 → 맞장구 1개 → 끝(증폭 금지) |
| 예시 카드 | "오늘 웃긴 거 하나만" / "오늘 제일 힘들었던 거 하나만" / "친구들이랑 뭐 했어" / "이번 주 최고의 순간" |
| 동작 조건 | 카드(기존 종이·인쇄) — 신규 앱 0 |
| 측정 | 응답 문장 수(평균 3→5), 거짓/회피 응답(0회), 부모 질문 증폭 횟수 |
| 비용 | 인쇄 10장. 0원 |
| 확장 단계 | (2단계) 가족 채팅방 '질문 스티커팩' / 다이어리 앱의 '한 문장' 프롬프트 |

## MP-05 — "탈락 카드 3문장" (QM-05)

| 항목 | 내용 |
|---|---|
| 형태 | **'탈락 카드'(A6 1장) — 3칸: 통제한 것 / 환경 요인 / 다음에 다르게 할 것 1개** |
| 흐름 | 탈락 통지 → 24h 안에 3칸 작성(10분) → 카드 부착 → 2~3일 내 다음 지원 |
| 동작 조건 | 종이 카드 또는 **기존 취업 트래커(스프레드시트)의 칼럼 3개 추가** — 신규 앱 0 |
| 측정 | 탈락 후 재지원 간격(미루기→작전일정), 자기평가 지표(자가 보고), 지원 주기 월 4→6건 |
| 비용 | 종이 1장 / 스프레드시트 3칸. 0원 |
| 확장 단계 | (2단계) 채용 플랫폼 지원 내역 → '탈락 회고' 모달 자동 생성(웹 기능 1개) |

> MP-05만 가장 '제품적인' 후보(기존 트래커 기능 확장). 나머지는 거의 행동 설계.

## MP-06 — "3-3-3 전환 + 내일 첫 일 카드" (QM-06)

| 항목 | 내용 |
|---|---|
| 형태 | **데스크 카드 1장(3-3-3 동작) + '내일 첫 일' A6 카드 팩(7장, 1일 1장)** / 또는 스마트폰 알림 1개(19:10 트리거) |
| 흐름 | 퇴근 → (알림 1개) 가방 정리 3분 → 씻기 3분 → 물 3분 → '내일 첫 일' 1줄 작성 → 자유시간(폰/OTT 그대로) |
| 동작 조건 | 시계 알림(기본), 종이 카드 — 신규 앱 0 |
| 측정 | 폰 멍 시간(90→60분), 취침 시각(2회/주 12시 전), '내일 첫 일' 작성 빈도(주 5회) |
| 비용 | 카드 인쇄 + 기본 알림. 0원 |
| 확장 단계 | (2단계) 기존 할 일 앱의 '오늘 첫 일 핀' 기능(가장 간단한 1개 버튼) |

## M-99. 최소 제품 표 요약

| QM | 최소 제품 | 신규 앱 | 비용 | 측정 지표 1개 |
|---|---|---|---|---|
| QM-01 | 가족 톡 공지 + 가방 사진 카드 | 없음 | 0원 | 주간 누락 0회 |
| QM-02 | 스크린 리뷰 시트(A4) | 없음 | 0원 | 주간 게임 h 조정 |
| QM-03 | 가족 회의 시트(A4·주1) | 없음 | 0원 | 엄마 수집시간 15분 |
| QM-04 | 질문 카드 10장 | 없음 | 0원 | 응답 3문장 |
| QM-05 | 탈락 카드 or 트래커 3칸 | 없음(기능 1개만) | 0원 | 재지원 간격 2~3일 |
| QM-06 | 데스크 카드+알림 1개 | 없음 | 0원 | 퇴근 후 멍 60분↓ |

> **결론**: 이 시스템에서 "제품"이 필요한 곳은 거의 없다. 필요한 것은 **기존 습관을 '환경의 고정장치'로 바꾸는 행동 설계**다.
> 시스템의 Output M이 "신규 제품 10개"가 아니라 "카드 6장 + 공지 1줄 + 칼럼 3개"인 것이 Quiet Move 자체의 본질이다.
