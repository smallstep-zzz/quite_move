# Domain 17 — 가계부·지출관리 (금전 루틴)

> 가계부는 '돈을 아끼는 도구'로 시작해 '지출을 심판하는 도구'로 변한다. 카테고리를 잘못 찍거나, 기록하는데도 지출이 안 줄면, 기록 자체가 부담이 된다.
> 문제는 '기록의 양'과 '자동화의 오류'다. 이 루틴의 진가는 **하루 1줄 기록이 소비를 '심판'이 아니라 '관찰'로 바꿀 때** 드러난다.

## A. Domain World

- 마이데이터 전면 시행(2022) 이후 가계부·자산관리 앱이 폭발 성장 — 누적 가입 1억 6,531만(2025.5, 중복 포함), 1인당 평균 3.5개 서비스. 토스 MAU 2,081만, 카카오페이 마이데이터 2,200만. (WORLD FACT)
- 뱅크샐러드 2024년 매출 196억원(+189%), 2025.2Q 첫 분기 흑자, 2026 하반기 IPO 목표. 편한가계부 누적 2,000만 다운로드. (WORLD FACT)
- MZ의 '짠테크': 무지출 챌린지(토스 포인트 지급), 거지방(소비 감시), 뱅크샐러드 '샐러드게임'(5명 팀 예산 경쟁, 참가 5,000명 중 1,460명 성공·평균 14만원 절약). (WORLD FACT)

## B. Persona (3)

- **P-MN1 서은지 (26, 사회초년생)**: 월급날 지출 계획을 세우지만 10일 만에 무너짐. 밤에 카드 내역 보며 한숨. '기록하면 아까워진다'는 믿음으로 시작했지만 지난주 기록부터 안 함. (PERSONA ASSUMPTION)
- **P-MN2 정경수 (38, 가장)**: 카드 내역 자동동기화 가계부. 그런데 'OO페이'로 찍힌 배달 주문이 '미분류'로 쌓임(오분류 12~15%). 분류 고치다 지침. (PERSONA ASSUMPTION)
- **P-MN3 이주희 (45, 전업주부)**: 주 1회 수기 가계부(엑셀). 몇 년째 쓰지만 '그래서 뭐랬는지' 결론 없음. 가족 지출 공유 요구가 '누가 얼마 썼나' 감찰이 됨. (PERSONA ASSUMPTION)

## C. Behavioral Loop (무한 루프)

```
지출 기록(수동/자동) → 카테고리 오류 발견 → 분류 수정 반복 → '굳이 왜 하나' 회의 → 기록 건너뜀 → 월말 잔액 충격 → '이번 달은 더 절약하자' 결심 → 1주일 지속 → 다시 기록 흐트러짐
```

- 핵심은 **기록이 '관찰'이 되어야 하는데 '심판'으로 작동**한다는 것. 오분류를 고치는 노동과, 월말 충격이 결심을 반복시키면서 기록 의지는 소모된다. (REFLECTION)

## D. Mental Model (주관적 인과)

- '기록하면 지출이 줄어든다' — 절반만 참인 신화. 기록 자체는 인식만 높이고, '기록→저축'을 연결하는 규칙이 없으면 감소로 이어지지 않는다. (CAUSAL INFERENCE)
- '자동 동기화면 충분하다' — 카테고리 오분류 12~15%가 쌓이면 월말 분석 자체가 무의미해진다. 자동화는 편하게 만드는 게 아니라 '고치게 만드는' 새 노동을 만든다. (PERSONA ASSUMPTION)
- '월말 결심은 진짜다' — 월말 잔액 충격은 일시적 고통이고, 재발 방지 규칙(고정 지출 우선, 이상치 알림)이 없으면 다음 달 그대로 반복된다. (REFLECTION)

## E. Memory (기억 구조)

- 기록된 지출은 '사건'(오늘 커피 5,000원)으로 기억되고, 기록하지 않은 지출은 '감정'(이번 달 어디에 썼지?)으로만 남는다. (PERSONA ASSUMPTION)
- 월말 충격은 '수치'로, 절약 성공은 '기분'으로 기억 — 결심의 기억과 결과의 기억이 분리되어 매달 '처음부터' 다시 결심한다. (REFLECTION)

## F. Adaptation Map (환경 - 행동 - 조정)

- 카드 내역 파편화(PG사명) (환경) → 자동동기화 앱 사용 (행동) → 오분류 수정 노동 (조정 실패). 일부는 수기 엑셀로 회귀, 또 일부는 '다른 앱'으로 갈아탐 — 마이데이터 앱을 3.5개씩 사용하는 원인. (REFLECTION)

## G. Reflection Timeline (주간)

| 요일 | 감정 | 행동 | 반성 |
|---|---|---|---|
| 월 | 다짐 | 월급 정리, 한도 설정 | "이번 달은 제발" |
| 화 | 무난 | 카드 자동 반영 확인 | "정리 잘 되네" |
| 수 | 짜증 | 분류 수정 10건 | "OO페이 도대체" |
| 목 | 회의 | 기록 안 봄 | "어차피 안 줄어" |
| 금 | 유혹 | 배달 주문(비정기) | "한 번쯤은 괜찮지" |
| 토 | 후회 | 카드 보며 한숨 | "또 이렇게" |
| 일 | 결심 | 다음 주 절약 다짐 | "월요일부터 제대로" |

- 주간 곡선은 '다짐(월)→회의(목)→후회(토)→재다짐(일)'으로 순환. 기록이 중단된 목요일이 바로 결심 파탄의 기점. (CAUSAL INFERENCE)

## H. Abstraction & Quiet Space

- 가계부의 Quiet Space는 **"오늘 딱 하나 남길 지출 1줄"**을 고르는 순간이다. 전체 내역을 '전부 심판'하지 않고, 그날의 기준점(앵커) 1개만 관찰하면 가계부는 심판이 아니라 거울이 된다. (REFLECTION)

## I. Turning Points (전환점)

- 9/13(일): "미분류 쌓인 것부터 고치지 말고, 오늘 라면 4,000원 하나만 남기자" — 전부 심판에서 1줄 관찰로 전환. (REFLECTION)
- 9/16(수): 샐러드게임 참가 후 '게임의 목표(예산 안)'가 '기록의 목표'보다 지속성에서 앞섬을 깨달음. (PERSONA ASSUMPTION)

## J. Friction (마찰)

- '모든 지출을 정확히'와 '기록하는 나'의 마찰 — 수동 입력은 월 180~240분, 자동 입력은 수정 노동. 어느 쪽이든 '기록 노동'이 남는다. (REFLECTION)
- '기록(관찰)'과 '심판(검열)'의 마찰 — 가족 공유 가계부는 감찰이 되어 기록의 정직함을 막는다. (PERSONA ASSUMPTION)

## K. Quiet Move Candidates (Quiet Space 분석)

- **KQ-MN-1 '지출 1줄'**: 하루에서 '가장 기억에 남는 지출 1건'만 1줄 기록. 자동 내역은 그대로 두고 관찰만. (REFLECTION)
- **KQ-MN-2 '기분 태그 1개'**: 그 1건에 만족/후회 태그 → 월말 '소비 감정 리포트'(충동 vs 만족). (PERSONA ASSUMPTION)
- **KQ-MN-3 '주간 소감 1문장'**: 일요일, '이번 주 지출을 1문장으로'. 월말 충격 대신 주간 경고. (PERSONA ASSUMPTION)

## L. Minimal Product (최소 제품)

- **'지출 1줄 수첩' (월 1권, 31칸)**: 날짜 1칸 + 기록 1줄 + 기분 태그 칸 + 주간 소감 4줄. 아무 데나 놓이는 종이 수첩. (REFLECTION)
- **Quiet Move 설치 포인트**: 밤에 카드 내역보기 시작할 때 — 1줄 칸만 채우고 닫는 행동이 30분 스크롤을 끊는다.

| 항목 | 내용 |
|---|---|
| 누구를 위한 것 | 기록 노동에 지친 가계부 초보 (P-MN1 우선) |
| 언제 쓰는가 | 매일 밤 1분, 일요일 소감 |
| 형태 | 31칸 수첩 월 1권 |
| 비용 | 인쇄비 이하 |
| 정확히 무엇을 제거하는가 | '전부 기록'의 노동과 월말 충격-재다짐 루프 |

## M. Counterfactual + Quietness Score

- **Base (현재)**: 기록 지속 10일 후 중단, 오분류 수정 주당 10건, 월말 충격-재다짐 매월 반복, '그래서 뭐랬는지' 없는 결론. Quietness Score = 34/100. (CAUSAL INFERENCE)
- **Intervention (KQ-MN-1+2+3)**: 1줄 관찰로 기록 지속 30일 중 27일, 수정 노동 10건 → 2건, 주간 경고로 월말 충격 선행 예방. 소비-감정 리포트로 '충동' 인식. Quietness Score = 61/100. (PERSONA ASSUMPTION)

### N-4. 시장·니즈·수익성 검증 (새 서비스 판단)

- **시장 존재**: ✅ — 마이데이터 1.65억 가입·자산관리 앱 실적 성장(뱅크샐러드 196억, 첫 흑자). 금전 기록은 보편 루틴.
- **니즈 존재**: ✅ — 오분류 12~15%·수동 입력 노동·'기록-저축 미연결'이 공통 미해결. 소비 1줄 + 기분 태그 + 주간 소감(감정-소비 연결)은 어느 앱에도 표준화 안 됨.
- **수익화 선례**: ✅ — 광고·금융상품 중개·구독(편한가계부)·게임화(챌린지) 모두 검증. 개인 '관찰' 레이어는 잔잔한 프리미엄(회고 리포트)으로 가능.
- **가장 큰 틈**: 자동화(정확성)와 수동(노동) 사이의 '경량 관찰' 레이어 — 1줄 기록 + 감정 연결 + 주간 리포트. 대형 앱은 정확성·광고에 집중해 이 층을 비웠음.
- **Quiet Move ↔ 신규 서비스**: "지출 1줄" = **1줄 캡처 + 기분 태그 + 주간 소비 감정 리포트 + 이상치 알림**. 마이데이터 연동 대형 앱과 반대로 '사람이 읽는 이야기'로 차별화, 광고 없는 구독 수익화. (PRODUCT HYPOTHESIS)
