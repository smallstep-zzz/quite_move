## B. Domain Persona — 대표 참가자 3

### P-F1 김대현 (41) — 가끔 가는 직장인 (주인공)
- 정체성/집착: 주말 1회 출조가 유일한 '내 시간'. **출조 준비 손실**(장비 누락·정보 소스 분산)을 싫어함. (PERSONA ASSUMPTION)
- 숙련도: 중. 바다·민물 두 토탈. 선상 1회/월.
- 장비: 릴 2세트, 바늘·추 케이스, 쿨러. 차 트렁크 상비.
- 시간/지출: 준비 2시간(금요일 밤), 주말 8시간. 월 출조 비용 10~15만(기름·예약·미끼).
- 과거 실패(MEMORY): 변방 포인트에서 채비 누락 → 출조 자체가 반토막(1회). 이후 **전날 밤 준비 체크 습관** 형성.
- 서비스: 오션피싱(조황), 국립해양조사원 물때, 카페 조행기, 네이버 지도 포인트 저장.

### P-F2 황기태 (36) — 장비를 깊게 파는 사람
- 정체성/집착: 조과보다 **세팅의 정확성**(릴 드랙·로드 액션·채비 규격)에 집착. "장비가 좋으면 조과는 따라온다" 신념.
- 지출: 신형 릴 우선 구매(월평균 20만+). 장비 리뷰·분해 사항 확인.
- 회고: 장비 튜닝 후 시험 필드에서 손맛 → 만족/재조정.

### P-F3 이수진 (33) — 조행록 기록 매니아
- 정체성/집착: **포인트·조과를 데이터로 남기는 것**에 집착(민물 루어). "기록이 곧 실력" 신념.
- 장비: 조행록 엑셀, 사진 폴더, 수온계, 지도 마커.
- 회고: 조과 없는 날도 "기록은 남았다"로 수용 — 기록이 감정 방파제 역할.

## C. Behavioral Loop — 분야의 반복 구조

```
출조 계획(물때·날씨·조류 체크) → 장비 준비(전날 밤) → 이동/현장
→ 채비 선택·투척 → 입질/조과(or 무) → 후 기억(사진·채비 메모)
→ 다음 출조 계획(가정에서 또 체크) ...
```

반복 지배 루프: **"준비-확인-수행-기록-계획"**. 준비와 기록이 'mar fatigue'를 좌우. (CAUSAL INFERENCE)

### 반복 빈도
| 루프 | 횟수 | 비고 |
|---|---|---|
| 정보 소스 체크 | 출조 전 3~4곳(물때·날씨·조황·포인트) | 반복 최대 |
| 장비 확인 | 전날 밤 30~60분 | 누락 두려움 |
| 조행 기록 | 빈손 날 0회(건너뜀) | ★ 기록의 부재 자체가 문제 |

## E. Memory Timeline — 기억의 누적

- **첫 대물 쾌감**: 두고 보는 사진·방법 기억 재생 → 같은 채비·포인트 반복 선택 (MEMORY)
- **채비 누락 실패**: 이후 전날 밤 체크 습관 형성 (MEMORY → Adaptation)
- **빈손 날 회고**: "그날 왜 1시간 먼저 다른 포인트를 안 갔을까" — 자책 기억이 다음 계획의 기준 (MEMORY → CAUSAL INFERENCE)

## K. Quiet Move Candidates

### KQ-F-1: "출조 체크리스트 1장" (전날 밤 1장 사진)
기존: 전날 밤 장비 확인 30~60분(+누락 불안).
변경: 채비 상자·로드·미끼를 나란히 두고 **1장 사진 + 체크리스트 5칸**. 출조 아침 2초 확인.
- 이미 있는 '전날 밤 준비 습관'을 **증거화**(사진)로 바꿔 불안만 제거. (QUIET MOVE, v1 QM-01과 동일 루프가 '장비'에 반복)

### KQ-F-2: "조행 리포트 5분" (귀가 후 6칸)
기존: 빈손 날 기록 0건, 성공 날도 사진+채팅 분산.
변경: 귀가 후 5분 **6칸 리포트 1장**(날짜·날씨·수온·포인트·채비·다음 계획). 사진 1장 첨부.
- 조행록의 '기록 행동'을 5분으로 축소 → 빈손 날에도 기록 유지(학습적 회고 가능). (QUIET MOVE)

### KQ-F-3: "Plan B 포인트 1곳" (현장 기준점)
기존: 현장 판단 실패 시 회전(조과 손실).
변경: 출조 전 '계획 포인트 + 대기 포인트 1곳' → 현장에서 2지점 기억 보유. (QUIET MOVE)

## L. Minimal Product

**KQ-F-2(조행 리포트 5분) 우선** — 6칸 카드 1장.

| 항목 | 내용 |
|---|---|
| 형태 | **'조행 리포트' A6 카드 1장(또는 메모앱 템플릿 6줄)** |
| 동작 | 귀가 후 5분 6칸 채움 + 사진 1장 |
| 비용 | 0원(종이/메모 템플릿) |
| 측정 | 조행 기록 작성률(0→80%), 다음 출조 시 이전 조행 참조 횟수 |
| 확장 | (2단계) 조황앱(오션피싱 등)에 '내 조행 리포트' 스크랩 — 기존 어종 예측과 마커 결합 |

> PRODUCT HYPOTHESIS: 조행록 매니아(P-F3)의 '레코드' 습관을 **5분 절차로 표준화**하면
> 빈손 날에도 학습 회고가 돌기 시작해 전체 마찰(정보 분산)이 줄어든다.
