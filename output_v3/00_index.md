# 파트3 · 비상장 초기투자 스타트업 스크리닝 — Part 3 로드맵 (등급·판정 기준)

> **"복제해도 될 소프트웨어 사업인가"** — 내가 만드는 SW와 같은 영역(10개 도메인)에서
> **비상장 + 초기 투자를 받은 회사** 19곳의 사업모델과 투자 시그널을 한눈에 보는 스크리닝.
> 이윤이 나는 사업(모방·관찰 대상)과 이윤이 안 나는 사업(회피 대상)을 카피캣 관점에서 판정한다.

## 목적·범위

- 기존 v3(상장 소프트웨어 24사) 조사는 폐기하고, **"초기 투자를 받은 비상장 기업"** 을 새 유니버스로 삼는다.
- 제외: 상장사(네이버·카카오·더존·한컴 등 — 구현할 영역이 아님), 폐업·청산 기업(운영여부 필터).
- 영역: 회계·세무 / 그룹웨어·협업 / AI 글쓰기·번역 / 음성·OCR / 결제·포인트 / 에듀테크·LMS /
  지역·취미·수집 / 웰니스·건강(의료·정신) / 금융라이트 / 마케팅·메시징.
- 이번 라운드 제외 도메인: **보안 SaaS·이커머스 도구** — (검증 가능한 비상장 후보를 확보하지 못함. 다음 라운드 과제).

## 판정 기준

비상장 기업은 재무 공시 의무가 없어 **매출·순이익·사원수를 얻을 수 없다(공개 데이터 부재).**
따라서 재무 대신 **"사업모델 + 투자 시그널"** 을 등급 축으로 쓴다. (인크루트 등에 재무가 공개된 1건은 예외 보강)

| 지표 | 정의 |
|---|---|
| 투자 시그널 | 라운드(프리A~시리즈F), 규모(억·$), 투자자 질(전략투자자·국부펀드·글로벌 VC) |
| 최신성 | 최근 라운드 연도 (또래 신호: 흑자전환, BEP, 거래액, MAU) |
| 판정 등급 | A · A- · B+ · B · C · D (아래 정의) |

| 등급 | 의미 |
|---|---|
| **A** | 후기 라운드(C+)·대규모 밸류 또는 흑자/규모 신호 — 이윤창출 검증·복제 관찰대상 |
| **A-** | 후기~중기(B~C) 라운드 + 뚜렷한 트랙션 — 조건부 복제 관찰대상 |
| **B+** | 초~중기(A~B) 라운드 + 명확한 시장 점유 — 틈새 복제 후보 |
| **B** | 초기 라운드(A) + 자생/검증 중 — 관찰 지속 |
| **C** | 투자·트랙션 시그널 취약 — 복제 회피 |
| **D** | 투자 후 이윤창출 실패(청산·폐업) — 반면교사 사례 |

## 한계 (반드시 읽기)

1. **InnoForest 로그인 게이트**: 매출·고용·투자금액 등 상세는 회원 전용(live-api 403). 공개 프로필 필드만 사용.
2. **투자 규모·누적액**: 언론 보도 값으로, 금액은 라운드 발표 시점 기준이며 후속 추가가 있을 수 있음.
3. **재무 미공시**: 등급은 투자 신호 기반 '시그널 등급'이지 확정 재무 등급이 아님.
4. **프로필과 실제의 시차**: 수퍼톤은 InnoForest 프로필이 '운영중'이지만 2026.07 하이브가 법인을 청산(실패 사례로 표기).
5. **'초기 투자' 기준 예외**: 매쓰홀릭은 공개 라운드가 없으나 2024 순이익 24.1억(흑자)으로 '투자 없이 자생' 사례를 보여줌.
6. 색인 기준일 2026-09-11. 수집은 공개 범위만, 조사 한계는 의도적으로 문서에 남긴다.
