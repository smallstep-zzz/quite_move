    Domain 07 — 취미·여가 후보 목록 (신규 분야 발굴 계획)

    v2 확장 계획: 기존 5개 분야(포켓몬 카드·LOL·낚시·패션·러닝)에 더해 어떤 취미·여가 분야를 추가 심층 연구할지 후보를 정리한 문서. 행동·감정·기억·적응·회고(Reflection) 축으로 다룰 수 있는 분야를 스펙 §5(서로 다른 성격) 기준으로 발굴한다. (PLANNING HYPOTHESIS) — 아직 시뮬레이션이 아니며 가설 단계.

    후보 선정 기준

    1. 기존 분야와 성격이 겹치지 않을 것 (수집 / 실시간 경쟁 / 현장 레저 / 반복 구매 / 자기계발)
    2. 반복 행동 루프 + 회고(Reflection)가 관찰 가능할 것
    3. 수작업 개인 시스템(엑셀·스크린샷·자가 채팅·즐겨찾기)이 생길 가능성이 있는 영역(스펙 §23)
    4. 한국 웹 환경에서 WORLD FACT(시장·문화) 수집 가능할 것

    후보 목록 (후보 20)

    # 후보 분야 유형 지배 마찰(가설) 기존과의 차별점 추천
    C01 개인투자(주식·코인) 금전·복기 차트 재확인 + 손실 회복(그만두기/다음 판) 루프 손실의 '회복 행동'이 중심 — 기존 어디에도 없음 ★
    C02 캠핑 현장·장비 장비 로드/구입 + 예약 경쟁 + 설치·철수 노동 낚시와 달리 '설치·정리·차 하중'이 지배 마찰 ★
    C03 보드게임·TRPG 오프라인 모임 모임 일정 조율 + 구매 욕구(가성비 계산) + 규칙 문서 사회적(타인 일정) 차원 — 기존에 없음 ★
    C04 사진·카메라 장비 수집+보관 장비 탐색·구입 + 원본/보관/출력 불안 포켓몬과 달리 '결과물(사진)의 정리'가 핵심 ★
    C05 가드닝(식물) 생명 관리 구매 + 환경 실패(죽음) 슬픔 + 구독 반복 '실패의 대상이 생명' — 슬픔의 회고 루프 ★
    C06 헬스·피트니스 자기계발+소비 체성분·기록·PT 회원권 + 식단 반복 구매 러닝과 달리 '음식·구독·체형' 소비 축 존재 ★
    C07 홈카페(커피 드립) 구독·장비 원두 구독 + 브루잉 장비 업그레이드 소형 구독 소비의 대표 케이스 ◐
    C08 자전거 장비 업그레이드 파츠 업그레이드 전쟁 + 안전 용품 구매 러닝과 일부 중복(심폐)이나 장비 축이 큼 ◐
    C09 반려동물(강아지·고양이) 생명·구독 분양 결심 + 사료/병원 리마인더 + 시안 가드닝과 유사하나 규모·정서 부담이 큼 ◐
    C10 클라이밍 성취 지표 그레이드 등급 + 재도전 실패 기록 러닝과 지표 축 중첩, 암장 구독 추가 ◐
    C11 미니어처·프라모델(건담) 제작+수집 시리즈 구매 + 사출·도색 완성 기준 없음 포켓몬과 달리 '제작 완료'의 끝이 없음 ◐
    C12 LP·헤드폰 오디오 장비 탐색 튜닝 탐색(스펙) + 재구매 시청각 비교 루프 — 정보 과잉 전형 ◐
    C13 베이킹·요리 재료 소비 레시피 재구매 + 실패 재시도 + 보관 반복 구매 하나, 재료 소진 문제가 특이 ◐
    C14 스키·보드 시즌제 시즌권·숙소 예약 + 장비 대여 캠핑과 예약 경쟁 중첩 ◐
    C15 등산·트래킹 현장·기록 정상 인증 사진 + 기록 앱 + 장비 낚시와 현장 축 중첩 ◐
    C16 골프 고비용 레저 라운딩 예약·레슨·시타 반복 비용 규모가 달라 '결제 마찰'이 큼 ◐
    C17 어항·수족관 생명+설비 수질 관리 + 물고기 구매 + 사고 가드닝과 관리 축 중첩 ◐
    C18 기계식 키보드 커스텀 장비+성능 파츠 기감 탐색 + 비용 오디오(C12)와 탐색 축 중첩 ◐
    C19 독서·필사 소프트 구매 스택(언샙) vs 읽기 부채 회고 축은 강하나 행동 루프가 약함 △
