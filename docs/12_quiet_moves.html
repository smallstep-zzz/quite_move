    L. Quiet Moves — 기존 행동 흐름 속의 작은 개입점

    출력 L (Quiet Moves) · 대한민국 2026 · 수능 D-66

    L. Quiet Moves — 기존 행동 흐름 속의 작은 개입점

    출력 L | 시뮬레이션에서 발견한 6개의 Quiet Move.

    정의(스펙 §30): 사람에게 완전히 새로운 생활방식을 강요하지 않고, 기존 서비스·앱·습관·인간관계를 유지하면서, 흐름 속 한 지점만 바꾸는 개입.

    L-1. QM-01 — "준비물 사진 한 장" (초등 가정)

    기존 흐름 (A→B→C→D)

    [전날 밤] 엄마가 내일 준비물 머릿속 정리
→ [아침]   엄마가 아이 가방을 열고 확인(불안)
→ [학교]   누락 발견 시 학교 연락 → 엄마 전달
→ [저녁]   엄마 단톡 재확인 ... 【매일 반복, 감정 비용 0.6~0.7】

    Quiet Move (A→B→C'→D) — 전날 밤, 아이가 넣은 준비물을 1장 사진으로 가족 톡에 업로드.

    [전날 밤] 아이가 스스로 준비물을 넣고 사진 1장(10초) → 가족 톡
→ [아침]   엄마는 사진 2초 확인(검색 없음)
→ [학교]   누락은 아이가 "직접 넣은 것"으로 사전 자체 점검됨
→ [저녁]   재확인 없음 ... 【고정 매일, 엄마 불안 회피(감정 0.3)】
    • 바꾸는 것: 확인의 대상(체크리스트→사진), 확인 주체(엄마→아이), 시점(아침→전날 밤)
    • 남기는 것: 가족 단톡, 아이의 폰, 기존 준비물 문화(스펙 §19 '찾기→메모하기' 유형)
    • 작동 원리: 엄마의 '불안 회피 루프'(F-01)는 있음을 아는 것이 아니라 증거를 보는 것에 반응한다. 사진=증거. 아이는 '주체성'의 스크립트를 얻는다(+1 책임감).
    • 비용: 0원. 폰 카메라·가족 채팅방(모두 보유).

    L-2. QM-02 — "주간 스크린 리뷰 15분" (중학생 가정)

    기존 흐름

    [매일] 폰 반납 규칙(23:30) → 아이 은닉(방/화장실) → 엄마 확인 강화
→ [충돌] 압수 → 반발 → 은닉 고도화 ... 【감시-은닉 루프, E=0.8】

    Quiet Move — 일요일 저녁 15분, 부모·아이가 함께 OS '주간 스크린 타임'을 열고 본다. 규칙 변경은 이 자리에서만 협상.

    [평일] 감시 대신 평온 유지(행동은 스크린 데이터가 보여줌)
→ [일요일 15분] 둘이 데이터 열람: 합계·앱별 · 시간
→ [협상] 새 규칙은 이 자리에서만(감정 고조 시 연기)
→ [평일] 규칙 실행 ... 【감시→공유, 은닉 동기 소실】
    • 바꾸는 것: 감시 수단(몸·확인) → 데이터 공유; 규칙 변경 지점 분리
    • 남기는 것: OS 스크린타임 앱(기본 제공), 폰 반납 규칙 자체, 가족 규칙 문화
    • 작동 원리: 엄마의 공백 불안(모르는 시간)을 객관 수치로 채운다. 아이는 "숨길 필요"가 사라져 협상에 들어간다. 실측: 게임 14h→12h, 갈등 4→2회.
    • 비용: 0원. 15분 투자. (부가: 10분도 가능 — 최소 실행 조건)

    L-3. QM-03 — "입시 정보 채널 2개 + 토요일 협의" (고등/입시 가정)

    기존 흐름

    [매일] 엄마 정보 채널 3곳 순회 + 스크랩 12개 (E=0.9의 최대 감정 비용)
→ [매일] 아들 문진(수치 질문) → 거짓/회피 보고
→ [불신] '숫자 프로토콜' 고착 ... 【과다공급형 루프】

    Quiet Move — 정보 소스를 2개로 고정하고, 가족 협의·정보 공유는 토요일 1시간으로 제한. 평일 문진 금지.

    [월~금] 엄마 신뢰 소스 2개만(카페 1 + 뉴스 1), 수집 15분 → 메모 1장
[토요일 1h] 가족 회의: 성적·학원·전략을 이 시간에만 업데이트
[평일] 아들은 공부, 엄마는 '오늘 하루' 한마디 문장만 ... 【주기 재배치】
    • 바꾸는 것: 정보 수집 주기(매일→주1회 집약), 공유 대상(엄마 혼자→가족), 질문 코드(수치→경험)
    • 남기는 것: 신뢰 카페·학원·EBS(모두 유지), 엄마의 정보 통제감(축소된 채널로 유지)
    • 작동 원리: 정보는 불안 회피 수단이므로 제거하면 안 되고 주기만 옮긴다. 실측: 기본 강도를 1/3로 하면서 아들과의 연결성은 상승.
    • 비용: 채널 축소 (무료). 주 1시간 회의 (가족 문화 수정 1건)

    L-4. QM-04 — "하루 1문장 체크인: 질문 코드 교체" (전 세대 공용)

    기존 흐름

    "오늘 몇 시간 공부했어?" / "점수 어땠어?" / "왜 말 안 하니?"
→ [응답] "몰라" / "응"(거짓) → 질문자 불만 ↑ → 더 세게 질문 ... 【단절형 루프】

    Quiet Move — 하루 1번, 하루 1문장의 '경험 질문'. 예: "오늘 하루에서 힘들었던 거 하나만" / "웃겼던 거 하나만"

    [저녁 5분] 경험 질문 1개(수치 금지)
→ [응답] 짧은 문장(3~5문장으로 충분)
→ [부모] 맞장구 1개 → 질문 종료(증폭 금지) ... 【대화의 진입 비용을 낮춤】
    • 바꾸는 것: 질문의 단위(숫자→경험), 응답 기대치(전모→단편)
    • 남기는 것: 식사·차 마실 때의 전통 대화 시간, 부모의 관심(질문은 유지)
    • 작동 원리: 거짓 보고(F-09)는 "전체를 보고해야 한다"는 부담에서 나온다 → 단편 1개만 보고하는 프로토콜로 바꾸면 거짓 유인 소멸. 실측: P05의 3문장 응답, P03의 40초 대화.
    • 비용: 0원. (가장 저렴한 QM)

    L-5. QM-05 — "탈락 해석 카드 24시간" (취업 준비생)

    기존 흐름

    탈락(사실) → 100% 내부 귀인("레퍼토리 없음") → 자기평가 -0.9
→ 지원 회피/과잉 수정 → 탈락 잔류 승압 ... 【내부형 루프, E=0.8】

    Quiet Move — 탈락 후 24시간 이내, 3문장 카드(노트/메모) 작성 — 통제·환경·다름 3칸.

    [탈락 통지] 24h 안에
[1] 내가 통제한 것: (예: 면접 답변 1개 수정)   → 내부 귀인을 '부분 통제'로
[2] 환경 요인: (예: 올해 채용 공고 수, 경력직 선호) → 외부 요인 인지
[3] 다음에 다르게 할 것 1개: (1개만)            → 행동 방향 고정
→ 24h 후 지원 재개(간격 2~3일) ... 【탈락을 사건으로 저장, 자기평가로 저장하지 않음】
    • 바꾸는 것: 탈락의 해석 프레임(총체적 자책→구획 귀인), 다음 행동의 즉시성
    • 남기는 것: 지원 트래커, 자소서, 취업 준비 문화(기존 도구 유지)
    • 작동 원리: 스펙 §14 — '자기평가 정보'로 저장되는 탈락만 가장 오래 남는다. 카드는 저장 라벨을 사건 정보로 바꾼다. 3문장이면 인지 부하가 낮다.
    • 비용: 10분. (정체성 카드 역할 — 저항 가능 3일 이내 형성)

    L-6. QM-06 — "퇴근 3-3-3 + 내일 첫 일 카드" (퇴근 후 성인)

    기존 흐름

    퇴근 → 소파 폰 90분(무의지) → 야생식 → 취침 01:00 → 다음날 피로 ... 【일주기형 루프】

    Quiet Move — 퇴근 후 10분 내 '전환 의식': 정리 3분 → 씻기 3분 → 물 3분, 그다음 '내일 첫 할 일 1개' 카드 1장.

    퇴근(19:00) → [가방 정리 3분]-[씻기 3분]-[물 3분]
→ '내일 첫 할 일 1개' 카드(포스트잇/노트) → 폰 자유시간(그대로)
→ 저녁 시간을 '다시 시작'의 장으로 ... 【무의지 전이→능동 전환】
    • 바꾸는 것: 퇴근 후의 첫 동작(소파→전환 루틴), 하루 마무리의 예약 지점
    • 남기는 것: 폰/OTT/야식 자유(전부 유지), 배달 주문(그대로), 취침 시간(목표는 자율)
    • 작동 원리: F-14의 '무의지 상태로의 전이'는 시작 조건이 만든다. 전환 동작 3개가 시작 조건을 바꾼다. '내일 첫 일'은 월요일 바다를 1개 섬으로 고정(명료함 0.4 실측).
    • 비용: 10분. (타이머 대신 '씻기' 등 자연 동작 사용 — 부가 앱 불필요)

    L-7. Quiet Move 공통 설계 원칙 (시뮬레이션에서 추출)

    1. 대상은 감정이 아니다, 루프의 매개변수다 — 불안·분노·걱정을 다루기보다 확인 주체·공개 여부·정보 주기·질문 단위를 바꾼다.
    2. 기존 도구만 사용한다 — 폰 카메라, OS 스크린 타임, 신뢰 카페, 메모장, 씻기. 신규 서비스 불요.
    3. 시간 비용은 0~15분 — 10초~15분. 감정 비용만 0.3~0.9 감소.
    4. '금지'가 아니라 '재배치' — 검색을 없애지 않고 주기를 옮기고, 확인을 없애지 않고 주체를 옮긴다.
    5. 시작 조건이 전부다 — 소파 자세, 아침 첫 동작, 질문 첫 단어 같은 '작은 시작'이 루프 방향을 결정한다.

    핵심 문장: "사람은 행동을 바꾸지 않는다. 행동이 도는 조건을 바꾸면 행동이 바뀐다."
