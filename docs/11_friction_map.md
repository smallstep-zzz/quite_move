## K-3. 추가 행동(스펙 §29) — 기대 흐름과 실제 흐름

```
[기대]  아이 준비 → 등교          (A→B)
[실제]  아이 준비 → [엄마 재확인] → 등교    (A→X→B)   ★ F-01
[실제]  아이 준비 → [가방사진 업로드→엄마 2초 확인] → 등교  (A→X'→B)  (개입 후)

[기대]  하교 후 휴식               (A→B)
[실제]  하교 → [폰 은닉: 방/화장실] → 캠핑 휴식          (A→X→Y→B)  ★ F-06

[기대]  면접 후 회복              (A→B)
[실제]  면접 → [탈락→자기평가→지원 회피] → 며칠 후 회복   (A→X→Y→Z→B) ★ F-12
```

**해석**: 추가 행동 X, Y가 반복·누적되면 습관으로 고정된다(스펙 §19). F-12의 경우 **시간으로 환산 불가능한 감정 인프라(Z)**를 만들었다.
