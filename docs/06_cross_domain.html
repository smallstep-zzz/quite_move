    교차 비교 — 11개 분야의 Quiet Move

    분야 집착 지배 마찰 Quiet Move 한 문장 (기준점)
    포켓몬 카드 시세 재확인 '결정 불안'(확인-후회 루프) 개봉 앵커 1장 판단의 기준점 1개
    LOL 복기 루프 게임 후 '해석 과다' 패배 1문장 노트 자기 판단의 기준점 1개
    낚시 출조 준비·기록 정보 분산+빈손 기록 손실 조행 리포트 5분 순간 기록의 기준점 1개
    패션 쇼핑 사이즈 불확실 반복 재판단(확인 루프) 사이즈카드 1장 신체 기준점 1개
    러닝 페이스·부상 숫자만 있고 감각 데이터 없음 주간 1문장 회고 몸의 기준점 1개
    개인투자 시세·손절 재확인 손실 인정 회피(물타기) 손실 1줄 사건정리 사건의 기준점 1개
    캠핑 장비 보유·예약 FOMO 소유(준비) vs 경험(자연) 즉석 키트 3상자 준비량의 기준점 1개
    보드게임 모임 유지·호스팅 룰 설명·일정 조율 부담 모임 1일 고정 슬롯 일정의 기준점 1개
    사진 촬영·보관 팽창 선택(정리) 비용 미해결 원본 1폴더 + 주 3장 선택의 기준점 1개
    가드닝 물주기·죽음 반복 죽음의 죄책감(처리 회피) 죽은 후 1장 + 관찰 1분 죽음의 기준점 1개
    헬스 측정(체중·인바디) 압박 숫자 판정 vs 몸 체감 주간 1줄 (느낌 기록) 감각의 기준점 1개

    수렴 구조 (CAUSAL INFERENCE)

    모든 분야에서 사람이 반복 지불하는 비용은
"결정 전 기준이 없어서 반복하는 재확인·재비교·재판단"이다.

Quiet Move = '기준점(앵커) 1개'를 기존 흐름에 추가하는 것.
  - 개봉 시대 앵커(포켓몬)
  - 패배 1문장(롤)
  - 조행 6칸(낚시)
  - 사이즈 4cm(패션)
  - 주간 감각 3문장(러닝)
  - 손실 1줄(투자) — 실패 지점을 재현해 실패의 쾌락 제거
  - 키트 3상자(캠핑) — 준비를 쇼핑으로 치환하는 FOMO 예약 제거
  - 고정 슬롯(보드게임) — 일정 중재와 룰 설명 부담 제거
  - 원본 1폴더(사진) — 미분류 팽창 대신 선택의 증명
  - 죽은 후 1장(가드닝) — 죽음의 죄책감을 버림이 아닌 기록으로
  - 주간 1줄(헬스) — 숫자 판정을 몸 체감의 기준으로 교체

    즉, 스펙 §36이 노리는 '계속 검색/비교/확인/기록'의 공통 원인은 각자가 이미 애매한 상태로 매번 새로 판단하기 때문이다. 기준점이 생기면 루프가 멈춘다.

    분야 성격별 Quiet Move 형태의 차이 (스펙 §5 대조)

    성격 사례 분야 Quiet Move 형태 특징
    강한 수집 욕구 포켓몬 카드 '판단 기준점' (앵커) 시세·희귀도라는 외부 변수를 내부 기준으로 고정
    실시간 경쟁 LOL '자기 판단 1문장' 감정 처리(해석)를 게임 밖으로 끄집어냄
    현장 활동 낚시 '순간 기록 6칸' 정보가 다수의 데이터(물때·수온)로 분산된 현장성에 대응
    반복 구매 패션 쇼핑 '신체 기준 1회 기록' 매번 재판단하는 사이즈 불확실 제거
    자기계발 러닝 '감각 3문장' 앱의 숫자 기록으로는 잡히지 않는 몸 데이터 보충
    자산·손실 개인투자 '사건 정리 1문장' 손실 인정 회피(물타기)를 사건 기록으로 끊어냄
    소유·준비 캠핑 '준비량 3상자' FOMO 예약·장비 구매를 최소 준비 세트로 고정
    정기 관계 보드게임 '일정 고정 슬롯' 일정 중재·룰 설명 부담을 캘린더 단일화로 제거
    기록·선택 사진 '선택 3장' 촬영 팽창을 주 3장 선택으로 수렴하게 유도
    돌봄·상실 가드닝 '죽음 기록 1장' 죽음의 죄책감을 의례(기록) 로 순환시킴
    측정·체감 헬스 '감각 1줄' 체중·인바디 숫자 판정을 몸 체감 1줄로 교체

    → 공통 루프(반복 확인)는 같고, 기준점의 '종류'만 분야에 따라 달라진다. (CAUSAL INFERENCE) → 새로운 성격(자산·소유·관계·기록·상실·측정)에서도 같은 수렴이 반복 — '기준점 1개'가 분야 무관한 보편 구조임을 암시.

    분야 공통으로 반복되는 요구 패턴

    1. 기준점 1개 (결정 전 판단의 고정)
    2. 기록의 단일화 (여러 앱·스샷·메모 분산 정리 — 스펙 §24)
    3. 회고의 경량화 (R1~R8을 전 과정으로 강제하지 않고 1문장으로 시작)
    4. 부정적 앵커의 프레임 전환 (손실·부상·자괴감 기억을 '사건 정보'로)
    5. 준비·소유의 최소화 (캠핑 키트 3상자, 사진 원본 1폴더 — '없음'의 의도를 허용)
    6. 측정에서 체감으로 (헬스·러닝 — 숫자 판정 빈도를 줄이고 몸의 반응을 기준으로)

    카테고리별 프로토타입 후보 (PRODUCT HYPOTHESIS)

    우선순위 후보 구현 형태 대상 앵커
    1 기준점 카드 시스템 A6 카드 1장 × 분야별 템플릿(공용 구조) 모든 분야
    2 사이즈카드 (패션 최고 점수) 4cm 줄자 기록 + 상품 비교 UI 패션
    3 손실 1줄 (개인투자 공동 2위) 매매노트 카드 + '평균단가 낮추기' 버튼 숨김 자산
    4 고정 슬롯 (보드게임 공동 2위) 캘린더 1개 + 룰 20분 기준표 정기 관계
    5 죽은 후 1장 (가드닝 공동 2위) 기록 카드 12장 (화분 곁 종이) 돌봄
    6 조행 리포트 (낚시) 6칸 메모 + 조황앱 스크랩 현장 활동
    7 개봉 앵커 (포켓몬) 개봉 시점 스크린샷 자동 제안 수집
    8 LOL 1문장 / 러닝 감각 3줄 / 헬스 주간 1줄 전적·러닝 앱의 '1줄 리뷰' 필드 경쟁·자기계발·측정

    이 목록을 제품 발명으로 곧바로 취급하지 않는다. 실세계 파일럿(Counterfactual 실험) 후 실제 동작 조건(PERSONA ASSUMPTION 검증)을 확인해야 한다(스펙 §38, §40).

    실사용 전제

    • 위의 모든 Quiet Move는 기존 사이트·앱·종이 위에서 동작 (0원, 적응 비용 0).
    • "사람에게 새로운 행동을 가르치지 않고, 이미 하고 있는 행동의 한 지점만 바꾼다." (스펙 §39)
    • 각 분야의 WORLD FACT(시장·문화)는 웹 리서치 기반, 개별 인물의 감정·기억·회고는 시뮬레이션(가정)임을 재확인.
