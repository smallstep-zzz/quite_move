    N. Counterfactual Results — 개입 전후 비교 (Baseline vs Intervention)

    출력 N | Quiet Move가 없는 세계(Baseline)와 있는 세계(Intervention)를 같은 페르소나로 비교(스펙 §31). 비교 축: 행동 단계 / 시간 / 반복 횟수 / 확인 횟수 / 앱 전환 / 기억 부담 / 감정 소모 / 불안 / 갈등 / 실수 가능성 / 비용 / 피로 / 타인 추가 작업.

    N-1. QM-01 (준비물 사진) — P07·P01

    축 Baseline Intervention 변화
    행동 단계 엄마 확인(아침)+재확인(저녁)+전달(누락 시) 아이 체크(밤)+사진 1장+엄마 2초 단계 3→2
    시간 주 60분(확인+) 주 25분(아이 체크 포함) -58%
    반복/확인 횟수 주 14회(재확인 7회) 주 7회(사실상 1회) -50%
    앱 전환 학급톡→학원앱→메모 3종 가족톡 1종 -2종
    기억 부담 엄마 머릿속 체크리스트 사진 1장 감소
    감정 소모(E) 0.6~0.7 0.3 -50%
    불안 아침마다 재확인(확인 없이 1주 불가) 2초 확인 후 종료 해소
    갈등 (무) (무) —
    실수 가능성 주 0.5건(누락) 주 0건 0건
    비용 0원 0원 —
    피로 엄마 피로+자책 낮음 감소
    타인 추가 작업 남편·학교 전달 1회/주 없음 감소

    판정: 전 축에서 Baseline 우위. 특히 시간(-58%)과 감정(-50%)이 동시에 개선 — Trade-off 없음.

    N-2. QM-02 (주간 스크린 리뷰) — P08·P03

    축 Baseline Intervention 변화
    행동 단계 은닉→확인→충돌→압수→재은닉 데이터 열람→규칙 협상→실행 단계 수 유사(질적 전환)
    시간 감시 확인 주 90분 리뷰 주 15분 -83%(감시 시간)
    반복/확인 횟수 화장실·방문 확인 일 3회 주 1회 크게 감소
    감정 소모(E) 0.8(아들 분노 0.9 포함) 0.5 -37%
    불안/갈등 진폭 상승(폭발 1건) 진폭 하락(폭발 0건) 갈등 4→2
    실수 가능성 은닉 고도화(부정행위화) 감시 대상 소멸 감소
    비용 감정+시간 합성 15분 감소
    피로 양측 피로 누적 낮음 감소
    타인 추가 작업 이웃 소음 민원 위험 없음 감소

    판정: Baseline의 감시는 시간 비용은 작지만 감정·사회적 비용이 지배적. Intervention은 작은 시간(15분)으로 감정 축 반전.

    N-3. QM-03 (정보 2채널·토요일 회의) — P09·P05

    축 Baseline Intervention 변화
    행동 단계 순회(3채널)→스크랩→질문 수집(2채널)+메모→주1회 회의 단계 3→2
    시간 주 315분(45분/일) 주 ~105분(15분×5+회의60) -67%
    반복/확인 횟수 정보 체크 45→15회/일 6회/일 -60%
    앱 전환 3채널+앱 다수 2채널 감소
    감정 소모(E) 0.9(최대) 0.5 -45%
    불안 정보 그만두면 불안(회피 소용) 토요일에 알게 된다는 구조적 안심 구조화
    갈등 문진→회피→거짓 보고 문진 폐지(경험 질문) 해소
    실수 가능성 정보 과잉으로 인한 잘못된 결정 위험 신뢰 소스 제한(결정 질 향상 기대) 감소
    피로 엄마 소진+아들 수치 낮음 감소
    타인 추가 작업 학원·카페 문의 수시 주 1회 정리 감소

    판정: 정보량은 줄었지만 결정 품질(2채널)과 가족 관계(온기)가 동시에 상승하는 가장 희귀한 개입.

    N-4. QM-04 (1문장 질문 코드) — 가구 B·C 공용 (P03, P05, P02 등)

    축 Baseline("몇 시간? 몇 점?") Intervention("오늘 힘들었던 거 하나만")
    응답 유형 "몰라" / 거짓(5시간) 3~5문장 경험 답변
    대화 지속 3초~30초 5~15분
    감정 소모 부모 0.7 / 자녀 0.6 부모 0.4 / 자녀 0.3
    거짓 보고 주 2회 관측 관측 0
    자녀의 다음 행동 회피·은닉 지속 다음날 화제 개방(P03 야구, P05 "엄마도 게임")
    비용 0원 0원

    판정: 동일 시간(식사), 동일 관심, 질문 단어 1개만 바꿔 효과가 뒤집힌 사례.

    N-5. QM-05 (탈락 카드 24시간) — P11

    축 Baseline Intervention
    후 행동 탈락 후 3일 지원 회피 2~3일 내 다음 지원
    감정 소모(E) 0.8(전체 자책) 0.5(부분 귀인)
    자기평가 -0.9 파동 -0.4~-0.5 파동(제한)
    기억 저장 유형 '자기평가 정보'(잔류 0.7) '사건 정보'(잔류 0.4)
    반복 기억 승압 23건 탈락에 최신 승압 구획화로 승압 제한
    지원 품질 과잉 수정(버전 파편화) 1판 원칙 유지
    피로 심리 소진+알바 부담 관리 가능

    판정: 시간 비용(10분) 대비 자기평가 보호 효과가 큰 개입. 단, 3문장 카드 습관 형성에 2~3회 반복 필요(기대).

    N-6. QM-06 (3-3-3+첫 일 카드) — P13/P15

    감정 소모 공허(0.7) + 야간 대기 긴장 명료성 소량(0.4)
    취침 00:40~01:15(지연) 12시 전 2회/주(개선 시작)
    다음날 피로 누적 감소(관측 제한)
    사회적 친구 연락 미룸(외로움) 금요일 모임 유지(회복 축)
    비용 0원 10분

    판정: 절대적 개선량은 작으나 시작 조건의 소프트 재설정 성공. 장기(1개월) 시뮬레이션에서 취침 시간 정규화를 기대(가정).
