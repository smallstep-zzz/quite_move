    G. Turning Points — 전환점 기록

    출력 G (Turning Points) · 대한민국 2026 · 수능 D-66

    G. Turning Points — 전환점 기록

    출력 G | 행동·상태가 실제로 바뀐 지점(스펙 §17~19). ⭐ 표시는 시뮬레이션 중 탐지된 전환점이고, 전환점 전후 상태를 포함해 기록한다.

    G-1. TP-A1 → TP-A2 — 가구 A: "엄마의 확인"에서 "아이의 인증"으로

    turning_point: TP-A1 (Day1 밤, 소형 전환점 → TP-A2에서 완성)
  before_state: 엄마가 아침 사전확인 + 하교 후 단톡 재확인 + 남편 몫까지 2중 체크. 아이는 수동.
  trigger_event: 월요일 체육복 누락 → 학교 톡 사진 → 밤에 "내일은 내가 가방 찍어 올릴게" 한마디
  immediate_emotion: 이준-수치(0.8) → 결심(0.5) / 엄마-자책(0.8)
  interpretation: 이준 - "엄마가 챙기지만 잊는 건 내 몫도 있다" / 엄마 - "내 체크가 무한히 늘어난다"
  decision: 이준 - 가방을 직접 열어 사진을 남긴다 / 엄마 - 시험적으로 허용
  behavior_change: Day3 직접 체크 성공 → Day4 사진 업로드 → Day5 엄마 사전확인 2→1회
  after_state: 매일 2분(아이) + 2초(엄마)로 확정. 준비물 누락 주 0회.
  persistence: 7일 시뮬레이션 내 유지됨(수용성 높음) ✱가구 단위로 채택
  affected_people: 이준(주체화 시작), 엄마(불안 하락), 남편(부담 분산), 이은채(규범 수용)

    전환을 만든 구체적 순간: "엄마가 챙긴다고 생각했지만 가방에서 없었던" 체육복 사건 — 탐지 대상인 A→X 사이의 X가 실제로 관측된 것.

    G-2. TP-B2, TP-B4 — 가구 B: "폰 압수 충돌"에서 "스크린 리뷰"로 (고비 2단)

    turning_point: TP-B2 (Day3 밤, 부정적 전환 — 자기강화 위기)
  before_state: (요약) 감시성 확인·단독 결정·질문 회피의 2주간 누적
  trigger_event: 야구 직관 무통보 → 엄마의 3회 전화 → 방문 slam + 폰 임시 압수
  immediate_emotion: 아들-분노(0.9) / 엄마-공포(0.9)
  interpretation: 아들 - "내 취미까지 통제 당한다" / 엄마 - "몰래 일을 벌이고 있다"
  decision: 엄마 - 격일 폰 회수 / 아들 - 이불 속 은닉(잠복)
  behavior_change: 감시 강화 → 은닉 강화 (자기강화 예고)
  persistence: 시뮬레이션 상 Day4까지 갈등 진폭 상승했으나 중단됨 ✱위기 신호

turning_point: TP-B4 (Day5 밤, 반전)
  before_state: 폰 압수 기억(잔류 0.7) + 감시 루프
  trigger_event: 엄마가 "이번 주말 스크린타임 보여줘" 합의안 제시 → 아이폰 주간 보고를 둘이 함께 열람
  immediate_emotion: 아들-당황(0.5)→수용, 엄마-긴장
  interpretation: 아들 - "수치를 보여주니까 오히려 통제가 덜한 느낌" / 엄마 - "공백이였던 걸 보게 되니 진정"
  decision: 규칙 개정(22시 보관 유지) + 주말 리뷰 정기화
  behavior_change: 감시(숨기는 게임) → 보고(공유하는 게임). 주말 게임 14h→12h
  after_state: Day6 '게임 레벨 물어보기', Day7 '고1부터 정량목표 협상'
  persistence: 7일 내 유지. 다만 단기이므로 취소 가능성 열어둠
  affected_people: 아들(자존감), 엄마(걱정 하락), 남편(가사 분담 증가)

    탐지 포인트: 반전의 트리거는 "통제의 철폐"가 아니라 "통제 대상이 객관적 데이터로 바뀐 것". 본질은 감시→공유.

    G-3. TP-C1 — 가구 C: "엄마의 정보 수집"이 아들 한 마디에 1/3로

    turning_point: TP-C1 (Day4 자정)
  before_state: 엄마가 정보 채널 3곳 순회·스크랩 12개/일, 아들은 "예"만. 정보 강도 증가 ↔ 수용 하락 동시 진행
  trigger_event: 정시 원서 논의(엄마 vs 아빠 대립) 중 아들 "엄마, 걱정 그만해도 돼. 난 정시로 가. 정보는 토요일마다 얘기하자"
  immediate_emotion: 아들-처음으로 의견 표출(약한 희열) / 엄마-충격→안도
  interpretation: 엄마 - "아이가 나를 배제하지 않고 협상을 정했다" / 아들 - "내가 통제권 일부를 얻었다"
  decision: 정보 채널 2개로 축소 합의 + 금요일 '잡담' 시작 합의
  behavior_change: 엄마 정보 체크 15→6회/일, 아들 잡담 응답(3문장) 시작
  after_state: 수면 6시간 1회 실현, 주말 '게임 제안'까지 온기 상승
  persistence: 7일 유지. 장기(수능 후) 관찰 필요
  affected_people: 아빠(거리), 엄마(불안 조절), 아들(자기주도성)

    전환의 성격: 큰 사건이 아니라 한 문장의 협상문. "정보를 멈춰달라"가 아니라 "정보 논의 시점을 정했다"는 데 의미가 있음 — 제거가 아닌 재배치.

    G-4. TP-O2 — P11: 탈락이 "사실"에서 "자기평가"로 저장된 지점

    turning_point: TP-O2 (Day6 새벽)
  before_state: 서류통과→면접 준비→자기평가 상승(카이前的) — 기대 부풀기
  trigger_event: 면접 탈락 이메일 확인(00:20)
  immediate_emotion: 충격(0.8). 우울 파동
  interpretation: "내가 부족해서" (통계적/환경적 사유 미고려 — 2026년 취업시장의 공급과잉은 해석에 없음)
  decision: 지원 목록 재작성(스프레드시트 대신 메모장) — 회피 메타 행동
  behavior_change: 다음 주 월·수 2곳 지원 계획(지원 간격 루틴 시도)
  after_state: '레퍼토리 없음' 신념 강화(잔류 0.7). 7일차 회복 의지 제한적
  persistence: 미해결 — 반복 탈락 시 잔류 승압 예상
  affected_people: 본인 + 어머니(둘째 주 통화질문 가능성)

    G-5. TP-F2 — P13/P15: "내일 첫 일" 카드가 주말 회복을 고정

    turning_point: TP-F2 (Day6 밤)
  before_state: 금요일 친구모임 후 회복 → 주말 놀이(OTT) → 월요일 앞둔 불안 반복
  trigger_event: "월요일 첫 할 일: 캠페인 리포트 1장" 노트 작성(직전 주말 실패 이후 2차 시도 성공)
  immediate_emotion: 명료함(0.4)
  interpretation: "월요일의 바다가 '첫 일 1개'로 고정됨"
  behavior_change: '금요일 회복 + 토요일 정리 + 일요일 예약' 3단 루틴 정착
  after_state: 퇴근 후 폰 4.5→3.5h, 12시 전 취침 2회
  persistence: 7일 내 유지.

    G-6. 근접 전환(near-misses) — 아직 전환이 안 된 지점(관찰 포함)

    근접 지점 관측 미전환 이유
    TP-B1 화장실 감시 엄마가 화장실 앞 대기(감시 표현) '공홈 루프'가 곧 깨졌으나, 감시 방식만 둠
    TP-O1 '지원 회피' 면접 후 지원서 작성 미루기 시작 탈락 전 '자기평가 하락' 예고형 — 해석 변경 개입 부재
    TP-F1 '더 자자' 결의 1일 반짝 팀장 야간 업무가 개인 의지보다 강했음(환경 제약)
    P02 반 배정 불안 엄마의 "모른다고 생각하자" 한마디 완화는 됐으나 '소속감' 이슈는 잔류 — 본 시뮬레이션 범위 밖

    G-7. 규칙 추출

    1. 전환점은 "큰 사건"(TP-B2)보다 "해석 재배치"(TP-B4, TP-C1)가 더 자주, 더 저비용으로 발생.
    2. 전환점의 본질은 항상 누가 무엇을 통제하는가의 이동이다(엄마→아이, 엄마→데이터, 정보→시점).
    3. 근접 전환(near-miss)이 실패하는 공통 원인 = 개인 의지에만 의존(TP-F1)하거나 환경을 바꾸지 않음(TP-O1). → Quiet Move는 여기서 "환경의 작은 고정"으로 설계된다.
