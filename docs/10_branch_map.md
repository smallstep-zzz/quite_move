# J. Branch Map — 인과 분기 지도

> 출력 J | 하나의 행동에 여러 원인이 있을 때 분기/수렴을 기록하고, 각 경로의 설명력을 검증(스펙 §24).
> 각 가지(Branch)에 `◎실측/○추론/△미검증` 표기를 달았다.

---

## J-1. "아침마다 가방을 확인하는 엄마(P07)" — 5분지

```
반복 확인(가방)
├─ 불안 회피 스크립트        ◎실측(작년 개학 사고 기억 재활성화)
├─ 자기 가치(역할)의 대체물  ○추론(재택 프리랜스 전환 후 유일한 통제 영역)
├─ 정보가 분산되서          ◎실측(학급톡·학원앱·늘봄 등 3종 분산)
├─ 아이와 남편의 기대 유지   ○추론(아빠 "엄마가 잘 챙긴다" 평판)
└─ 습관(무의식 루틴)        ◎실측(매일 같은 시각, 같은 순서)
```

**수렴 검증**: 가방 확인 빈도(주 14회)와 "사진 루틴 도입 후 빈도(9회)" — 확인량은 `불안 회피`+`정보 분산` 가지로 70% 설명. `자기 가치` 가지는 감정 비용(자책) 설명에 기여.

## J-2. "수행평가 점수를 '몰라'로 답하는 아들(P03)" — 4분지

```
"몰라"(대화 회피)
├─ 점수 자체가 낮다(82 예측)     ◎실측(실제 87 — 예측 낮음)
├─ 숫자를 말하면 잔소리           ◎실측(과거 경험 — 질문 5분 지속)
├─ '무가치한 보고' 프레임        ○추론(자존감과 점수 분리 못함)
└─ 대체 대화 채널 부재           ◎실측(야구 카톡은 활성)
```

**검증**: "좋아졌잖아" 한마디 후 다음날 점수 공개(Day4) — **반응 조건**이 대화 개방을 결정. `숫자→잔소리` 가지의 설명력이 가장 높았음.

## J-3. "9월 모평 수학 71점(하락)에 대한 엄마의 반응(P09)" — 3분지+중복

```
교재 변경/강사 문의/상담
├─ 정보 수집 습관의 연장        ◎실측(채널 3곳 순회가 일상)
├─ '점수 하락=위기' 신념        ◎실측(작년 참사 기억 — 타인 가정)
└─ 대안 의사결정 수단의 부재     △미검증(기대 — 상담은 아직 진행 전)
```

**수렴**: 실제로 행한 행동(즉시 상담 예약)은 `정보 수집`+`위기 신념` 두 가지의 **합교집합**. → 개입은 이 수렴 지점을 **시점 재배치**(토요일)로 하여 가볍게 막음(TP-C1).

## J-4. "지원서를 4번 다시 쓰는 P11" — 2층 분지

```
과잉 수정
├─ A층: 자기표현 불확실성
│   ├─ '실패 경험' 문단에서 과거 사건성을 잃음      ◎실측
│   ├─ 이력서 포맷 파편화(파일 3개)               ◎실측
│   └─ 비교 프레임(합격 후기 탐색)               ○추론
├─ B층: 미래 위험 회피(내용 확정=책임질 결과물)
│   ├─ '결과가 나빠도 "내가 썼다"를 피하려는 무망감' ○추론
│   └─ 탈락 잔류의 승압                        ◎실측(잔류 0.7)
└─ C층: 도구 미준비(버전 관리 부재)              ◎실측
```

**검증**: 버전 충돌(Day1)은 명백한 C층. 그러나 4번 재작성은 B층(책임 회피)이 지배하는 것으로 보임 — **기계적 도구 지원**만으론 안 풀리는 층이라는 예고.

## J-5. "퇴근 후 소파 폰(P13/P15)" — 4분지

```
소파 폰 90분
├─ 해방 선언(일 안 함의 몸짓)     ◎실측("멍=다시 쉰다" 진술)
├─ 무의지 상태로의 전이           ◎실측(일하다 → 그냥 폰 순서 확인)
├─ 외로움(1인 자취)의 자기위로    ○추론(배달·OTT 반복 — 대화 없음)
└─ 야간 대기 때의 분노 재생       ○추론(전날 메신저 응답 회고)
```

**검증**: 친구 모임(사람 관련 가지)이 회복을 이끈 것과 '월요일 첫 일 카드'가 도구 지원이 아니라 **빈칸(내일)의 고정**으로 작용한 것 — `무의지 상태` 가지가 핵심 결절로 확인됨.

## J-6. 분기 구조의 메타 학습

| 유형 | 예 | 대응 전략 |
|---|---|---|
| 다원인 분기 | 가방 확인(J-1) | 가지 분리 후 '지배 가지'만 조준 |
| 수렴 분기 | 수학 상담(J-3) | 수렴 지점의 '빈도' 제어 |
| 다층 분지 | 지원서(J-4) | 도구(C)→프레임(B) 순으로 개입 |
| 상태 전이 | 소파 폰(J-5) | 전이 지점의 '시작 조건' 통제 |

> 관찰: 대부분의 분기는 예상보다 깊지 않는다. 3~4가지 수준에서 실제 행동 설명이 수렴된다는 점이 시뮬레이션 상 유의미한 판단이다(스펙 §25 "더 이상 인과가 나오지 않으면 종료").
