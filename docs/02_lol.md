## B. Domain Persona — 대표 참가자 3

### P-L1 정민수 (25) — 실력 집착 솔랭러 (주인공)
- 정체성/집착: "왜 졌는지 모르는 상태를 가장 싫어함" — 결과보다 **통제가능성**에 집착 (스펙 §14 예시의 실제화). (PERSONA ASSUMPTION)
- 숙련도: 골드~플래티넘. 챔피언풀 6개. 빌드 따라가는 수준 (금손 아님).
- 목표: 다이아 승급, 본인 인증. 개인 트레이닝에 몰입.
- 시간: 평일 2시간, 주말 4시간(야간). 주말 밤샘 1회.
- 지출: RP 소액, 신속히 변하는 빌드를 위한 '시즌 패스'류, 크루 대회 참가비.
- 성공 경험(MEMORY): 플래티넘 승급전에서 미드 다리우스로 +30 점수 — "내 판단이 맞았다" 기억.
- 실패 경험(MEMORY): 다이아 승급전 2번째 연패 → 밤샘 추가 3판 → 승급 자체를 미룸(불안 회피).

### P-L2 최예린 (22) — 친구들과 즐기는 플레이어
- 정체성/집착: 혼자보단 4인 듀오. ARAM·일반 선호. "즐기는 사람이 잘한다" 신념.
- 장비: 게임용 노트북(중저가), 마이크·디코. 보조금식 소액.
- 회고: 게임 후 '오늘 웃긴 플레이'를 카톡/클립으로 공유 — **자발적 회고가 긍정 방향**.

### P-L3 박건 (18) — 초보 (막 시작)
- 정체성/집착: 모두에게 "캐리하고 싶다" 욕구 강함. 손따라가기 어려움.
- 우려: 소위 "게임에 진심" 밈 부담, 친구들 실력 격차.
- 회고: 패배 시 "컴퓨터 잘못/파밍" 등 외부 귀인 70%. (성급한 원인 추론)

## C. Behavioral Loop — 분야의 반복 구조

```
게임(한 판) → 승/패 → 전적 확인(감정적) → 복기(사이트·리플레이)
→ 빌드/메타 검색(유튜브·거시레포트) → 룬/아이템 설정 → 다시 게임
```

이 루프의 특징: **결과의 감정 처리가 '게임'이 아니라 '확인·검색'으로 이동**. (CAUSAL INFERENCE)

### 반복 빈도 (P-L1, 주간)
| 루프 | 횟수/주 | 비고 |
|---|---|---|
| 게임 | 16~20판 | — |
| 전적/복기 루틴 | 5~8회 | 사이트 2~3곳 순회 |
| 빌드·메타 검색 | 4~6회 | 게임 후 반복 |
| 새벽 밤샘 | 1회 | 후회 농후 |

## H. Abstraction / Generalization — (부정확한) 패턴

- "메타를 따라가면 이긴다" → 실제로는 소스마다 상이해 혼란만 증가 (CAUSAL INFERENCE)

## I. Turning Points

- **TP-L-1**: 연패 후 복기 멈춤 2주 → 폼 회복. "복기의 존재 자체가 스트레스" 자각. (REFLECTION)
- **TP-L-2**: 듀오 크루(토요일)에서 처음 이겨 "즐기면서 하니 잘되네" 경험 → 과열 조절 가능성 등장. 
- **TP-L-3**: 새 시즌 초 "이번엔 3판 규칙" 선언 실패 → 사후 해석 "나만의 규칙은 오래 못 간다".

최대 전환점: **TP-L-1** — 복기 루프의 자기 정당성을 깨는 순간. 여기에 Quiet Move 배치. (CAUSAL INFERENCE)

## K. Quiet Move Candidates

### KQ-L-1: "패배 1문장 노트" (게임 직후 30초)
기존: 승패 확정 → 전적 사이트·리플레이·유튜브 순회(1~3시간/주).
변경: 게임 직후 **"오늘 진 이유 중 내가 통제한 것 1개"** 만 30초 노트. 복기 사이트는 그 후 1곳만.
- 제거: 복기 멀티 전환 2곳+ / 추가: 30초 1문장. (QUIET MOVE)
- 원리: 통제 가능성에 대한 답은 이미 플레이어 머릿속에 있다(깊은 추상화가 가능한 사람). 자료 대신 **판단 기준점**을 만들 뿐.

### KQ-L-2: "연패 냉각 타이머" (2연패 후 30분 이탈)
기존: 연패 → 감정 이월 → 추가 판.
변경: 2연패 시 **무조건 30분 이탈**(물·산책·눈 휴식) → 이탈이 tilt 방지. 시작 조건 변경. (QUIET MOVE)

### KQ-L-3: "듀오 크루 시간 확대" (긍정 루프 강화)
기존: 혼자 솔랭다수 + 크루 1일.
변경: 크루 시간을 주 1회→2회, '즐거운 회고' 축으로 재배치(즐기는 사람이 잘한다 신념과 연결). (QUIET MOVE)

## L. Minimal Product

**KQ-L-1(1문장 노트) 구현** — 기존 도구 재사용.

| 항목 | 내용 |
|---|---|
| 형태 | **복기용 '1문장 카드' + 기존 전적 앱의 '게임 후 리뷰' 칸의 1줄 필드** |
| 동작 | 게임 끝 → 30초 문장 1개 → (선택) 전적 사이트 1곳 |
| 비용 | 0원. 전적 앱의 기존 UI 재사용 |
| 측정 | 주간 복기 시간, 연패 후 재게임 간격, 밤샘 횟수 |
| 확장 | (2단계) 승·패 모두 1문장 → 월간 '통제 가능 요인' 리스트 자동 수집 |

> PRODUCT HYPOTHESIS: 강한 게임 플레이어는 복기 자료가 아니라 **자기 판단의 기준점**을 원한다.
> '1문장'은 결과 해석 주기를 경험에서 자기 인지로 옮긴다. (스펙 §33 — 인지 과정에 Quiet Move)
