    A. Domain World — 분야의 세계 상태

    항목 내용 태그
    메타 최신 패치 패치 26.17 최신 (2026.9.5~). 신규 챔피언 '유나라' 합류, 편입 173 챔피언 WORLD FACT
    티어 정보 채널 MetaBot/SeeMeta/METAsrc 각각 매일 승률·픽률 재계산. 소스마다 순위 상이(메타를 '몇 개나' 보느냐가 마찰) WORLD FACT
    현재 S급 예시 서폿 세라핀·소나, 탑 모데카이저·케일, 원딜 미스 포츈·케틀린, 미드 말자하·야스오 WORLD FACT
    데이터 소비 문화 전적 사이트·리플레이·유튜브·빌드 가이드가 '복기'의 표준 회로 WORLD FACT
    게임 후 복기 게임 종료 → 전적 확인 → 복기 → 빌드 검색 → 재게임의 순환이 일반적 WORLD FACT

    B. Domain Persona — 대표 참가자 3

    P-L1 정민수 (25) — 실력 집착 솔랭러 (주인공)

    • 정체성/집착: "왜 졌는지 모르는 상태를 가장 싫어함" — 결과보다 통제가능성에 집착 (스펙 §14 예시의 실제화). (PERSONA ASSUMPTION)
    • 숙련도: 골드~플래티넘. 챔피언풀 6개. 빌드 따라가는 수준 (금손 아님).
    • 목표: 다이아 승급, 본인 인증. 개인 트레이닝에 몰입.
    • 시간: 평일 2시간, 주말 4시간(야간). 주말 밤샘 1회.
    • 지출: RP 소액, 신속히 변하는 빌드를 위한 '시즌 패스'류, 크루 대회 참가비.
    • 성공 경험(MEMORY): 플래티넘 승급전에서 미드 다리우스로 +30 점수 — "내 판단이 맞았다" 기억.
    • 실패 경험(MEMORY): 다이아 승급전 2번째 연패 → 밤샘 추가 3판 → 승급 자체를 미룸(불안 회피).

    P-L2 최예린 (22) — 친구들과 즐기는 플레이어

    • 정체성/집착: 혼자보단 4인 듀오. ARAM·일반 선호. "즐기는 사람이 잘한다" 신념.
    • 장비: 게임용 노트북(중저가), 마이크·디코. 보조금식 소액.
    • 회고: 게임 후 '오늘 웃긴 플레이'를 카톡/클립으로 공유 — 자발적 회고가 긍정 방향.

    P-L3 박건 (18) — 초보 (막 시작)

    • 정체성/집착: 모두에게 "캐리하고 싶다" 욕구 강함. 손따라가기 어려움.
    • 우려: 소위 "게임에 진심" 밈 부담, 친구들 실력 격차.
    • 회고: 패배 시 "컴퓨터 잘못/파밍" 등 외부 귀인 70%. (성급한 원인 추론)

    C. Behavioral Loop — 분야의 반복 구조

    게임(한 판) → 승/패 → 전적 확인(감정적) → 복기(사이트·리플레이)
→ 빌드/메타 검색(유튜브·거시레포트) → 룬/아이템 설정 → 다시 게임

    이 루프의 특징: 결과의 감정 처리가 '게임'이 아니라 '확인·검색'으로 이동. (CAUSAL INFERENCE)

    반복 빈도 (P-L1, 주간)

    루프 횟수/주 비고
    게임 16~20판 —
    전적/복기 루틴 5~8회 사이트 2~3곳 순회
    빌드·메타 검색 4~6회 게임 후 반복
    새벽 밤샘 1회 후회 농후

    D. Mental Timeline — 감정·기분·생각

    시점 상태 태그
    랭크 시작 전 긴장·목표 의식 SIMULATED EMOTION
    연패 중 분노 0.9 → "왜?" 반복 질문 SIMULATED EMOTION
    역전승 쾌감 → "이 기분 때문에..." SIMULATED THOUGHT
    게임 후 복기 자기고문적: "그 순간 왜 그걸 상대했지" SIMULATED THOUGHT
    새벽 2시 1판 더 후회 예감 ↔ 흥분 교차 SIMULATED EMOTION
    승급 실패 후 주말 포기("이번 시즌 버려") 특별하면 재도전 REFLECTION

    E. Memory Timeline — 기억의 누적

    • 승급 성공 기억: 미드 다리우스로 역전 — 이후 "물리전(직전 파밍) vs 감각" 신념 생성 (MEMORY → CAUSAL INFERENCE)
    • 연패 기억: "연패 시즌이 계속되면 무너진다" → 복기 멈춤 조건 자체가 악화 (MEMORY)
    • 챌린저 스트리머와 비교: 티어 낮은 내가 왜 이걸 보는가 → 자괴감 0.6 (SIMULATED EMOTION)
    • 기억 재활성화 시점: 새 시즌 시작, 패치 초기, 친구가 "어떻게 하지" 물어볼 때 (MEMORY)

    F. Adaptation Map — 스스로 만든 해결책

    개인 도구 방식 태그
    스크린샷 복기 노트 패배 직후 스크린샷+1문장 메모 SIMULATED EXPERIENCE
    챔피언풀 엑셀 6개 챔피언별 강점·상성 표 — 갱신 빈도 낮음 SIMULATED EXPERIENCE
    '전적 사이트 즐겨찾기' OP.GG·meta 등 3개 즐겨찾기 폴더 — 전환 반복 SIMULATED EXPERIENCE
    자체 규칙 "연패 3회 중단" 시행 실패율 높음(밤샘으로 이어짐) SIMULATED EXPERIENCE
    듀오 약속 캘린더 친구와 토요일 고정 — 긍정 루프의 축 SIMULATED EXPERIENCE

    G. Reflection Timeline — 회고가 발생한 순간

    발생점 R 단계 내용
    새벽 3시 마지막 판 후 R4~R6 "요즘 계속 연패하면 화가 나. 왜? → 지는 것보다 통제 불능한 느낌이 싫은 것 같다" (깊은 추상화)
    승급 성공 후 목욕 R5~R8 "내 판단이 맞다는 게 제일 중요" → 다음 티어 목표 설정
    패치 초기 R1~R3 "메타 따라가니까 지쳤어" → 일단 내 챔피언 확인
    시즌 종료 R6~R8 "올해는 복기보다 게임 수가 문제였지" — 원인 다른 쪽으로 외부화 Start

    H. Abstraction / Generalization — (부정확한) 패턴

    • "메타를 따라가면 이긴다" → 실제로는 소스마다 상이해 혼란만 증가 (CAUSAL INFERENCE)
    • "많이 확인할수록 정확해진다" → 복기 루프가 게임 시간을 잠식 (스펙 §36 '계속 검색')
    • "나는 게임에 감각이 없다" → 초보(외부 귀인) vs 숙련(부분 내부 귀인)의 대비

    I. Turning Points

    • TP-L-1: 연패 후 복기 멈춤 2주 → 폼 회복. "복기의 존재 자체가 스트레스" 자각. (REFLECTION)
    • TP-L-2: 듀오 크루(토요일)에서 처음 이겨 "즐기면서 하니 잘되네" 경험 → 과열 조절 가능성 등장.
    • TP-L-3: 새 시즌 초 "이번엔 3판 규칙" 선언 실패 → 사후 해석 "나만의 규칙은 오래 못 간다".

    최대 전환점: TP-L-1 — 복기 루프의 자기 정당성을 깨는 순간. 여기에 Quiet Move 배치. (CAUSAL INFERENCE)

    J. Friction Map — 비용 지도

    ID 행동 시간 감정 인지 사회 설명
    J-L-1 게임 후 복기 멀티 검색 2~3시간/주 0.7 높음 — ★ 사이트 전환 반복 — 스펙 §36 '계속 검색·비교'
    J-L-2 연패 감정 처리 지연 — 0.8 높음 — 분노 가라앉지 않고 다음 판으로 이월
    J-L-3 빌드·메타 최신화 부담 4~6회/주 0.5 높음 — 패치 초기에 극대화
    J-L-4 밤샘 후 다음날 — 0.6 높음 0.4 일상 침범
    J-L-5 티어 비교 강박 — 0.6 중간 0.5 크루·게시판 비교

    K. Quiet Move Candidates

    KQ-L-1: "패배 1문장 노트" (게임 직후 30초)

    기존: 승패 확정 → 전적 사이트·리플레이·유튜브 순회(1~3시간/주). 변경: 게임 직후 "오늘 진 이유 중 내가 통제한 것 1개" 만 30초 노트. 복기 사이트는 그 후 1곳만. - 제거: 복기 멀티 전환 2곳+ / 추가: 30초 1문장. (QUIET MOVE) - 원리: 통제 가능성에 대한 답은 이미 플레이어 머릿속에 있다(깊은 추상화가 가능한 사람). 자료 대신 판단 기준점을 만들 뿐.

    KQ-L-2: "연패 냉각 타이머" (2연패 후 30분 이탈)

    기존: 연패 → 감정 이월 → 추가 판. 변경: 2연패 시 무조건 30분 이탈(물·산책·눈 휴식) → 이탈이 tilt 방지. 시작 조건 변경. (QUIET MOVE)

    KQ-L-3: "듀오 크루 시간 확대" (긍정 루프 강화)

    기존: 혼자 솔랭다수 + 크루 1일. 변경: 크루 시간을 주 1회→2회, '즐거운 회고' 축으로 재배치(즐기는 사람이 잘한다 신념과 연결). (QUIET MOVE)

    L. Minimal Product

    KQ-L-1(1문장 노트) 구현 — 기존 도구 재사용.

    항목 내용
    형태 복기용 '1문장 카드' + 기존 전적 앱의 '게임 후 리뷰' 칸의 1줄 필드
    동작 게임 끝 → 30초 문장 1개 → (선택) 전적 사이트 1곳
    비용 0원. 전적 앱의 기존 UI 재사용
    측정 주간 복기 시간, 연패 후 재게임 간격, 밤샘 횟수
    확장 (2단계) 승·패 모두 1문장 → 월간 '통제 가능 요인' 리스트 자동 수집

    PRODUCT HYPOTHESIS: 강한 게임 플레이어는 복기 자료가 아니라 자기 판단의 기준점을 원한다. '1문장'은 결과 해석 주기를 경험에서 자기 인지로 옮긴다. (스펙 §33 — 인지 과정에 Quiet Move)

    M. Counterfactual — 개입 전후 (P-L1, 2주 시뮬레이션)

    축 Baseline Intervention(KQ-L-1+L-2)
    복기 시간 주 2~3시간 주 30분
    연패 후 행동 1~2판 더 30분 이탈 → 명확
    감정 파동 0.8 0.5
    게임 수 16~20판 14~16판(같은 실력 유지 가능성)
    밤샘 1회 1회(개선 50% 기대)
    메타 검색 4~6회 2회

    Quietness Score: 행동변화 4 · 효과 4 · 반복 5 · 적응비용 5 · 호환성 4 · 감정감소 4 · 시간감소 4 · 인지감소 4 · 경제가치 2 · 확장성 4 → 총 40/50

    결론: LOL의 핵심 마찰은 게임이 아니라 게임 후의 해석 루프다. 복기를 '여러 사이트 정독'에서 '1문장 자기 판단'으로 옮기는 것이 가장 작고 큰 변화다. (QUIET MOVE)
