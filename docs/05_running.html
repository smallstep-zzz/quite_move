    Domain 05 — 러닝 (자기계발 · 기록 · 크루)

    분야 성격: 자기계발 (기록·페이스·부상·커뮤니티) · 파일: 05_running.md

    A. Domain World — 분야의 세계 상태

    항목 내용 태그
    규모 러닝 인구 1,000만 시대 추정. 최근 6개월 경험률 64.1%, 조깅 규칙참여(주1회 30분+) 약 330만 WORLD FACT
    대회 서울마라톤 약 4만명(역대최대), 대회 참여 의향 58.3% WORLD FACT
    장비 공개 러닝화가 최대 구매품(66.6%), 최다 비용 투자(64.2%). '브랜드보다 성능(반발력·에너지리턴율)' 중심(신발 분해 리뷰, 더 나) WORLD FACT
    앱/소셜 러닝 앱 이용 32.8%(주 용도: 기록관리 71%), 스트라바·NRC. 해시태그 400만+, 크루 2,000개+ WORLD FACT
    문화 78.9% 혼자 러닝. '쉽게 시작하지만 꾸준히 어렵다' 50.9%. 크루 비호감 44.9%(에티켓 갈등: 보행자 불편) WORLD FACT
    트렌드 런트립(2021대비 소셜 6배), 트레일러닝, 소셜러닝, IP 이벤트(포켓몬 런 5,000명) WORLD FACT
    산업 러닝 관련 매출 최대 75% 확대, 웨어러블 약 2,000억 WORLD FACT

    B. Domain Persona — 대표 참가자 3

    P-R1 서지후 (29) — 기록 집착 러너 (주인공)

    • 정체성/집착: 페이스·거리·스트라바 세그먼트 순위에 집착. "오늘도 P.R(개인기록)" 기대. (PERSONA ASSUMPTION)
    • 숙련도: 하프 완주 경험, 풀 마라톤 목표(하반기).
    • 장비: 러닝워치(GPS), 스트라바+, 나이키 페가수스류 2켤레, 러닝복 3벌.
    • 시간: 주 4회(월·수·금·일). 주간 40~60km. 아침 6시 출발.
    • 지출: 러닝화 2~3개월에 1켤레(15~30만), 대회 참가비, 앱 구독.
    • 과거 실패(MEMORY): 무리한 주간 거리 증가 → 무릎 통증 2주 휴업 → 이후 '무리 = 멈춤' 기억이 행동을 움직임.

    P-R2 임채윤 (24) — 러닝 크루 활동가

    • 정체성/집착: 혼자보단 '함께+커피+사진'. 소속감이 목적. NRC·크루 단체 채팅.
    • 지출: 크루 모임 커피·굿즈, 이벤트 티셔츠.
    • 회고: 달린 후의 '사진·커피'가 에너지 — 비기록형 회고(긍정).

    P-R3 민태오 (40) — 초보 (부상 두려움)

    • 정체성/집착: "혼자 시작해볼까" 상태. 부상(무릎·정강이) 공포로 출발 지연.
    • 지출: 러닝화 1켤레 계획. 구매 결정 부담 큼(성능 데이터 과다).
    • 회고: 스스로 "주 2회 30분부터" 목표 — 낮은 자기 신뢰.

    C. Behavioral Loop — 반복 구조

    런닝(시간·코스) → 워치/앱 기록(GPS·페이스) → 스트라바 업로드
→ 세그먼트 순위·친구 비교(즐거움 or 자괴감)
→ 주간 거리 그래프 확인 → 다음 러닝 계획(코스·장비·일자) ...

    반복 지배 루프: "달리기-기록-비교-계획". 기록과 비교가 루프의 감정 담당자. (CAUSAL INFERENCE)

    반복 빈도

    루프 횟수 비고
    러닝 세션 4회/주 —
    스트라바 업로드/비교 4회/주 + 수시 열람 ★ 기록·비교의 이중 부담
    주간 거리 확인 1회(일요일) 월간 그래프 집중
    러닝화/장비 고민 수시 성능 데이터 과다 시 분석 마비

    시점 상태 태그

    E. Memory Timeline

    • 첫 완주 기억: 10km 최초 완주 — "나는 할 수 있다" 신념의 근거 (MEMORY)
    • 부상 휴업 부정적 앵커: 무릎 통증 2주 — 이후 '무리의 대가'로 기억되어 과도한 신중함 유발 (MEMORY)
    • K.O. 순간(기록 단절): 앱 오류로 거리 미저장 → "이번 주 기록이 비었다" — 기록 의존성 확인 (MEMORY)

    F. Adaptation Map — 스스로 만든 해결책

    개인 도구 방식 태그
    스트라바 세그먼트 순위 비교가 동기부여 — 동시에 자괴감 유발 SIMULATED EXPERIENCE
    수첩 '부상 일지' 통증 부위·날짜 메모 — 공간 부족으로 비정기화 SIMULATED EXPERIENCE
    주간 거리 엑셀 WB(week build) 계획 1줄 — 그래프 인식 목적 SIMULATED EXPERIENCE
    크루 단체 채팅(P-R2) '오늘 나 달림' 인증 — 긍정 사회 루프 SIMULATED EXPERIENCE
    '걸리면 쉰다' 자체 규칙 시행 시 통증·무리 판단 어려움 SIMULATED EXPERIENCE

    G. Reflection Timeline

    발생점 R 단계 내용
    일요일 주간 그래프 R2~R5 "이번 주 거리가 목표보다 10km 모자라네 → 왜지? → 수요일 저녁을 빼먹었지"
    대회 후 회고 R5~R8 "훈련 양보다 강도가 문제였어 → 내년엔 간헐적 템포를 넣자" (유의미한 일반화)
    부상 후 R3~R6 "거리를 늘리면 항상 무릎이 아파 → 무리는 나에게 휴업이야" — 신중함 과잉 프레임

    H. Abstraction / Generalization — (부정확한) 패턴

    • "페이스가 안 늘면 훈련이 소용없다" → 페이스 외(컨디션·근력·회복) 무시 (CAUSAL INFERENCE)
    • "무리는 곧 부상" → 통제된 초과(온도·강도)까지 회피하는 과잉 보수화 (MEMORY의 부정적 일반화)
    • "앱 기록이 곧 실력" → 기록의 오류·배터리 등이 몰래 실력 오인 (MEMORY)

    I. Turning Points

    • TP-R-1: 첫 10km 완주 — '러너' 정체성 획득. (전환점)
    • TP-R-2: 부상 휴업 후 '훈련 계획 축소' 결정 — 페이스보다 회복 우선 원칙 4주 유지. (positive)
    • TP-R-3: 세그먼트 압박으로 스트라바 열람 늘고 달리기 자체 지연 — 비교 루프의 시작. (negative)

    J. Friction Map — 비용 지도

    ID 행동 시간 돈 감정 인지 사회 설명
    J-R-1 스트라바 비교 열람 수시 — 0.6(순위 시) 중간 0.5 ★ 기록·자괴감 루프
    J-R-2 주간 거리 그래프 확인 10분 — 0.5 중간 — 목표 대못시 불만
    J-R-3 부상 조짐 판단 — — 0.7 높음 — ★ '쉬어야 하나 말아야 하나' 판단 부담
    J-R-4 러닝화 구매 결정 1~2주 15~30만 0.5 높음 — 성능 데이터 과다 → 분석 마비
    J-R-5 크루 에티켓(주행성) — — 0.3 낮음 0.7 사회적 갈등 요소(WORLD FACT에 일치)

    K. Quiet Move Candidates

    KQ-R-1: "주간 1문장 러닝 회고" (감각 축 보충)

    기존: 주간 그래프 = 거리·페이스 수치만. 페이스 안 늘면 무의미+자괴감. 변경: 주 1회 10분, 거리·페이스 대신 '컨디션·부상 조짐·즐거움' 1문장씩 기록(수첩 3줄). - 앱이 못 담는 감각 축을 1문장으로. 부상 조짐의 판단 데이터 확보. (QUIET MOVE — 인지 과정) - 예: "화요일 정강이 살짝 뻐근 → '쉬는 날' 1일 추가" — 불안 판단(쉬어? 달려?)의 기준점.

    KQ-R-2: "대회 등록 잠금 규칙" (훈련 근거 결합)

    기존: 감정적으로 등록 → 훈련 부족으로 미달성 자괴감. 변경: 등록 전 "이번 주 러닝 킬로 수 ≥ 목표" 확인 절차 1회. (QUIET MOVE)

    KQ-R-3: "부상 감지 2일 휴식 카드" (판단 부담 제거)

    기존: '쉬어? 달려?' 반복 판단 → 불안. 변경: 통증 감지 시 자동 2일 휴식 카드 1장. 판단을 제거, 규칙으로 대체. (QUIET MOVE)

    L. Minimal Product

    KQ-R-1(주간 1문장 회고) 우선 — 10분 습관 하나.

    항목 내용
    형태 수첩 3줄(또는 러닝 앱의 '주간 감각 칸' 3개)
    동작 일요일 10분: 컨디션/부상 조짐/즐거움 3문장
    비용 0원
    측정 부상 이탈일 수, 주간 계획 위반(무리) 횟수, 회고 작성 유지율
    확장 (2단계) 스트라바 주간 리뷰에 '감각' 필드 — 거리 데이터와 병행 자동 요약

    PRODUCT HYPOTHESIS: 러너의 기록은 거리·페이스(앱)로 소진되고 감각(컨디션·부상)은 잃는다. 1문장 감각 축이 '쉬어야 하냐'는 불안 판단의 기준점을 만든다. (스펙 §33 인지 과정)

    M. Counterfactual — (P-R1, 4주)

    축 Baseline Intervention(KQ-R-1+R-3)
    '쉬어? 달려?' 판단 횟수 주 3~4회 주 1회(규칙 기반)
    부상 이탈일 2주(휴업) 1주(조짐 조기 캐치)
    스트라바 자괴감 주 3회 주 1.5회
    주간 거리 절제(회복 우선) 실패 40% 성공 70%
    감정 파동 0.6 0.4

    Quietness Score: 행동변화 3 · 효과 4 · 반복 4 · 적응비용 5 · 호환성 5 · 감정감소 4 · 시간감소 3 · 인지감소 4 · 경제가치 3 · 확장성 5 → 총 40/50

    결론: 러닝의 마찰은 '못 달려서'가 아니라 기록(숫자)만 있고 감각(몸) 데이터가 없어서 페이스·부상 판단이 막막한 것이다. (QUIET MOVE)
