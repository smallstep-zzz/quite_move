## B. Domain Persona — 대표 참가자 3

### P-R1 서지후 (29) — 기록 집착 러너 (주인공)
- 정체성/집착: **페이스·거리·스트라바 세그먼트 순위**에 집착. "오늘도 P.R(개인기록)" 기대. (PERSONA ASSUMPTION)
- 숙련도: 하프 완주 경험, 풀 마라톤 목표(하반기).
- 장비: 러닝워치(GPS), 스트라바+, 나이키 페가수스류 2켤레, 러닝복 3벌.
- 시간: 주 4회(월·수·금·일). 주간 40~60km. 아침 6시 출발.
- 지출: 러닝화 2~3개월에 1켤레(15~30만), 대회 참가비, 앱 구독.
- 과거 실패(MEMORY): 무리한 주간 거리 증가 → **무릎 통증 2주 휴업** → 이후 '무리 = 멈춤' 기억이 행동을 움직임.

### P-R2 임채윤 (24) — 러닝 크루 활동가
- 정체성/집착: 혼자보단 '함께+커피+사진'. 소속감이 목적. NRC·크루 단체 채팅.
- 지출: 크루 모임 커피·굿즈, 이벤트 티셔츠.
- 회고: 달린 후의 '사진·커피'가 에너지 — 비기록형 회고(긍정).

### P-R3 민태오 (40) — 초보 (부상 두려움)
- 정체성/집착: "혼자 시작해볼까" 상태. **부상(무릎·정강이) 공포**로 출발 지연.
- 지출: 러닝화 1켤레 계획. 구매 결정 부담 큼(성능 데이터 과다).
- 회고: 스스로 "주 2회 30분부터" 목표 — 낮은 자기 신뢰.

## C. Behavioral Loop — 반복 구조

```
런닝(시간·코스) → 워치/앱 기록(GPS·페이스) → 스트라바 업로드
→ 세그먼트 순위·친구 비교(즐거움 or 자괴감)
→ 주간 거리 그래프 확인 → 다음 러닝 계획(코스·장비·일자) ...
```

반복 지배 루프: **"달리기-기록-비교-계획"**. 기록과 비교가 루프의 감정 담당자. (CAUSAL INFERENCE)

### 반복 빈도
| 루프 | 횟수 | 비고 |
|---|---|---|
| 러닝 세션 | 4회/주 | — |
| 스트라바 업로드/비교 | 4회/주 + 수시 열람 | ★ 기록·비교의 이중 부담 |
| 주간 거리 확인 | 1회(일요일) | 월간 그래프 집중 |
| 러닝화/장비 고민 | 수시 | 성능 데이터 과다 시 분석 마비 |

## K. Quiet Move Candidates

### KQ-R-1: "주간 1문장 러닝 회고" (감각 축 보충)
기존: 주간 그래프 = 거리·페이스 수치만. 페이스 안 늘면 무의미+자괴감.
변경: **주 1회 10분, 거리·페이스 대신 '컨디션·부상 조짐·즐거움' 1문장씩** 기록(수첩 3줄).
- 앱이 못 담는 **감각 축**을 1문장으로. 부상 조짐의 판단 데이터 확보. (QUIET MOVE — 인지 과정)
- 예: "화요일 정강이 살짝 뻐근 → '쉬는 날' 1일 추가" — 불안 판단(쉬어? 달려?)의 기준점.

### KQ-R-2: "대회 등록 잠금 규칙" (훈련 근거 결합)
기존: 감정적으로 등록 → 훈련 부족으로 미달성 자괴감.
변경: 등록 전 "이번 주 러닝 킬로 수 ≥ 목표" 확인 절차 1회. (QUIET MOVE)

### KQ-R-3: "부상 감지 2일 휴식 카드" (판단 부담 제거)
기존: '쉬어? 달려?' 반복 판단 → 불안.
변경: 통증 감지 시 **자동 2일 휴식** 카드 1장. 판단을 제거, 규칙으로 대체. (QUIET MOVE)

## L. Minimal Product

**KQ-R-1(주간 1문장 회고) 우선** — 10분 습관 하나.

| 항목 | 내용 |
|---|---|
| 형태 | **수첩 3줄(또는 러닝 앱의 '주간 감각 칸' 3개)** |
| 동작 | 일요일 10분: 컨디션/부상 조짐/즐거움 3문장 |
| 비용 | 0원 |
| 측정 | 부상 이탈일 수, 주간 계획 위반(무리) 횟수, 회고 작성 유지율 |
| 확장 | (2단계) 스트라바 주간 리뷰에 '감각' 필드 — 거리 데이터와 병행 자동 요약 |

> PRODUCT HYPOTHESIS: 러너의 기록은 거리·페이스(앱)로 소진되고 **감각(컨디션·부상)은 잃는다**.
> 1문장 감각 축이 '쉬어야 하냐'는 불안 판단의 기준점을 만든다. (스펙 §33 인지 과정)

### N-4. 시장·니즈·수익성 검증 (새 서비스 판단)

- **시장 존재**: ✅ — 러닝 인구 1,000만·러닝화 1조원·앱 GMV $4.5B. 인구·매출 모두 성장 중.
- **니즈 존재**: ✅ — 페이스·거리·심박은 넘치지만 "오늘 몸 상태·무릎 감각·회복" 로그가 없음. 부상 원인 데이터(과훈련 감각 신호)를 수집하는 서비스 부재. **주 1문장 감각저널 = 통합 회고 + 부상 예고 데이터 계층** 확보 가능.
- **수익화 선례**: ✅ — 구독(스트라바 90%·런데이 프리미엄), 코칭 플랜 유료, 대회 수수료(런너블). "감각·회고" 계층은 스트라바 페이월·가민 하드웨어와 대비되는 경량 무료 진입이 가능.

- **Quiet Move ↔ 신규 서비스**: "주간 감각 3문장" = **감각저널 + 체감강도(RPE) 기반 오버트레이닝 경보**. NRC·런데이·스트라바 데이터와 연동 가능하고, 러닝화 교체·부상 추천 코칭으로 수익화. (PRODUCT HYPOTHESIS)
