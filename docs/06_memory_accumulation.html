    F. Memory Accumulation — 기억·감정의 누적과 재활성화

    출력 F (Memory Accumulation) · 대한민국 2026 · 수능 D-66

    F. Memory Accumulation — 기억·감정의 누적과 재활성화

    출력 F | 과거 사건이 현재 해석과 판단을 바꾸는 방식을 mental_memory로 관리(스펙 §13~14). 형식: event / emotion / intensity / belief_update / residue, 그리고 시뮬레이션 중 관측된 재활성화 사건(activation).

    F-1. P07 김서연 — "준비물 사고" 기억이 확인 습관을 만든 과정

    mental_memory:
  - event: "작년 겨울, 이준 준비물 누락으로 개학 첫날 학교에서 연락"
    emotion: 당황
    intensity: 0.9
    belief_update: "확인해야 내가 버틸 수 있다(체크=안전)"
    residue: 0.6

    재활성화 체인 (observed)

    Day1  학급톡 공지 → 체육복 복기 → "작년 개학 사고" 기억 활성화(잔류 0.6 승압)
   → 마찰행동: 아침 사전확인 + 사후 재확인 2회 → 감정(자책) 누적
Day2~3  매일 같은 트리거(아침 가방, 단톡 알림) → 같은 루프 재실행
Day4  아이 사진 업로드 → '체크로 해결됨' 새 기억 생성(강도 0.6, 잔류 0.4)
   → 기존 belief의 경쟁 가설 등장: "아이가 확인하면 안심할 수 있다"

    해석: 기억은 단순 저장이 아니라 현재 맥락과 유사하면 자동 활성화되는 스크립트. 엄마의 확인은 "불안 해소"가 아니라 "불안 회피 스크립트 실행"이었다.

    F-2. P08 박지혜 — "폰 압수 사건"이 자녀 대화의 해석 틀을 만든 과정

    mental_memory:
  - event: "작년 여름, 폰 압수 → 아들이 방문 두드리며 반발 → 이웃 민원"
    emotion: 충격/분노
    intensity: 0.9
    belief_update: "폰은 폭발의 근원. 다루면 갈등"
    residue: 0.7
  - event: "중3 내신이 남았는데 현재 성적이 중위권"
    emotion: 조바심
    intensity: 0.8
    belief_update: "지금 안 하면 늦는다(서두름=사랑)"
    residue: 0.5

    재활성화 체인 (observed)

    Day1 "수행평가 점수?" → '폰=갈등' 기억 활성화 → 질문을 줄임(여전히 불안)
Day2 학원비 결정 단독 처리 → '서두름=사랑' 신념 → 아들 방문 닫음
Day3 야구 직관 → "미리 말해" 지적 → 기존 '통제' 스크립트 실행
Day5 스크린타임 공동 리뷰 → "공백(모름)이 불안의 원인"이라는 새 기억 생성(강도 0.6)
   → 폰 압수 기억이 '감시 도구'에서 '대화 도구'로 재맥락화

    F-3. P05 김우진 — "숫자로 평가받던 경험"의 누적

    mental_memory:
  - event: "9월 모평 당일 국어 난조 → 엄마 옆에서 학원 상담"
    emotion: 수치
    intensity: 0.8
    belief_update: "내 가치는 점수로 측정된다"
    residue: 0.5
  - event: "반복되는 '몇 시간 공부했어' 질문"
    emotion: 죄책감
    intensity: 0.5
    belief_update: "숫자를 보고해야 함 → 보고를 피로워함"
    residue: 0.6

    재활성화 체인 (observed)

    Day1 엄마 "국어 3점 틀린 거 봤니?" → '점수=가치' 기억 활성화 → "응"(거짓) → 회피
Day2 수학 71하락 → '숫자로 평가' 재활성화 → 상담 예약 OK
Day3 "오늘 몇 시간?" → '보고=부끄러움' → 5시간이라 말함(실제 2.5)
Day4 정시 선언 → 최초로 '내가 정한다' 기억 생성 → 이후 정보 수용력 상승

    F-4. P11 박소연 — "탈락 경험의 잔류 누적" (취준)

    mental_memory:
  - event: "서류 탈락 23회 누적"
    emotion: 무기력
    intensity: 0.6 (누적 가중)
    belief_update: "나는 스펙이 부족하다"
    residue: 0.5
  - event: "이번 면접 탈락(Day6)"
    emotion: 충격(0.8) + 자책
    belief_update: "면접 레퍼토리가 없다(자기평가 -0.9)"
    residue: 0.7

    재활성화 체인 (observed)

    Day2 자소서 '실패 경험' 문단 → '나는 부족' 기억 활성화 → 4번 재작성(과잉 수정)
Day5 면접 2문항 꼬임 → '레퍼토리 없음' 갱신 → 탈락 확정 시 몰락감
Day7 "월요일 2곳 지원" → 탈락 잔류(0.7)가 다음 지원서의 자신감을 낮출 것으로 관측됨

    관찰: 탈락의 잔류는 결과 정보가 아니라 자기평가 정보로 저장된다. 1건의 탈락이 23건의 이전 탈락 기억을 승압시키는 현상 — 실패의 가중 평균이 아니라 최신 실패의 가중치가 지배한다.

    F-5. P13/P15 이하린 — "퇴근 후 무기력" 기억의 일주일 주기

    mental_memory:
  - event: "야간 메신저 대응(수요일 밤)"
    emotion: 긴장
    intensity: 0.7
    belief_update: "퇴근 후에도 대기해야 안심"
    residue: 0.6
  - event: "금요일 친구 모임에서 회복"
    emotion: 안정
    intensity: 0.6
    belief_update: "사람 만나면 회복된다"
    residue: 0.4

    재활성화 체인 (observed)

    Day1~3 야간/퇴근 트리거 → '퇴근 후에도 대기' 기억 반복 활성화 → 폰 멍
Day5 친구 모임 → '사람=회복' 기억 활성화 → 금요일 밤 회복 → 주말 기분 고정
Day7 '내일 첫 일 카드' → '퇴근 후 대기' 기억을 '계획된 다음 행동' 기억으로 대체(부분)

    F-6. 누적 효과 계산 모델(관측 규칙 정리)

    스펙 §14의 요소를 실제 잔류 값으로 역추정한 결과:

    저장 요소 관측 규칙
    사건 중요도 강한 1회(폰 압수, 면접 탈락)는 잔류 0.7~0.8로 고정
    반복 횟수 미세한 반복(준비물 누락, 야간 대기)은 intensity × 반복로그로 누적
    최근성 3일 이내 사건이 해석 틀을 지배(탈락 1건이 23건을 승압)
    현재 상황 유사성 아침 가방=작년 겨울, 폰=작년 압수 → 상황 유사 시 자동 활성화
    해결 여부 "해결됨"으로 저장된 사건은 잔류 하락(가구 A의 사진 루틴)
    반대극 사건 강한 긍정(친구 모임)은 부정 기억 잔류를 직접 낮춤(선택적 재맥락화)

    중요 관점: 잔류 감소는 "시간 경과"보다 "해석 변경(재맥락화)"에서 온다. → 이 점이 이후 Quiet Move 설계의 핵심 원리가 된다(기억을 지우려 하지 않고 해석을 바꾸는 개입).
