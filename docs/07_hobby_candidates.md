# Domain 07 — 취미·여가 후보 목록 (신규 분야 발굴 계획)

> v2 확장 계획: 기존 5개 분야(포켓몬 카드·LOL·낚시·패션·러닝)에 더해
> **어떤 취미·여가 분야를 추가 심층 연구할지** 후보를 정리한 문서.
> 행동·감정·기억·적응·회고(Reflection) 축으로 다룰 수 있는 분야를 스펙 §5(서로 다른 성격) 기준으로 발굴한다.
> (PLANNING HYPOTHESIS) — 아직 시뮬레이션이 아니며 가설 단계.

---

## 후보 선정 기준

1. **기존 분야와 성격이 겹치지 않을 것** (수집 / 실시간 경쟁 / 현장 레저 / 반복 구매 / 자기계발)
2. **반복 행동 루프 + 회고(Reflection)가 관찰 가능**할 것
3. **수작업 개인 시스템**(엑셀·스크린샷·자가 채팅·즐겨찾기)이 생길 가능성이 있는 영역(스펙 §23)
4. **한국 웹 환경에서 WORLD FACT(시장·문화) 수집 가능**할 것

## 추천 6개 선정 근거 (성격 다양성 최대화)

| 새 Domain | 유형 대표 | 기존 5개 분야와의 거리 | 예상 최종 Quiet Move 형태 |
|---|---|---|---|
| 개인투자 | 금전·회복 루프 | 완전 신규 (손실 '다음 판' 감정) | 손실 1문장 '사건 정리' |
| 캠핑 | 장비+예약·철수 | 낚시와 다른 '설치/정리 노동' | 출장 체크리스트 1장 → 회수 메모 |
| 보드게임/TRPG | 오프라인 모임 | 사회적 차원 신규 | 모임 1일 고정 슬롯 |
| 사진/카메라 | 장비+보관 정리 | '결과물 정리'가 지배 마찰 | 원본 1개 폴더 규칙 |
| 가드닝(식물) | 생명 실패·슬픔 | 정서적 슬픔의 회고 신규 | 죽은 후 '사진 1장' 의례 |
| 헬스·피트니스 | 소비+자기계발 | 러닝과 다른 '음식·구독' 축 | 주간 단백·운동 1줄 |

> 이 추천 6개는 **"금전 회복 / 장비·노동 / 사회적 모임 / 결과 정리 / 생명 관리 / 소비+자기계발"**
> 여섯 가지 성격을 중복 없이 채우는 조합이다. (PLANNING HYPOTHESIS)

## 진행 방법 (확정 시)

1. 각 후보를 `08_~~.md` ~ `<N>_~~.md` (A~M 13섹션, 기존 Domain 형식)으로 심층 작성
