# O. Cross-Persona Validation — 여러 대표 페르소나에서의 재현성

> 출력 O | 각 Quiet Move가 다른 생활 조건의 페르소나에서도 재현되는지, 어디서 실패하는지 검증(스펙 §32-O).
> 검증 방법: 시뮬레이션 내 대응 페르소나에 QM '이식' 가상실험 + 근거(행동 조건 공통성)로 판정.

---

## O-1. QM-01 (준비물 사진) — 재현 가능 페르소나

| 페르소나 | 재현 가능? | 이유 |
|---|---|---|
| P01 초5 남 | ✅ 원본 | — |
| P02 초6 여 | ✅ 가능 | 학원 준비물·진학 자료(원서 복사본 등)도 '사진 1장' 객체로 처리가능 |
| P03 중2 남 | △ 약함 | 준비물 의존은 줄고 '성적/약속'이 갈등 축 → 객체(사진) 전환은 부차적 |
| P06 고2 여 | ✅ 부분 | 수행평가 준비물·도서관 대출 → '사진 리스트' 활용可(학원 앱 대체) |
| P11 취준 여 | ✅ 변형 | '지원 서류 체크리스트 사진/1판'으로 이식(버전 파편화 F-11 억제) |
| P08·P09 엄마 | ✅ 반복 | 초등 이후 단계에서도 '확인 객체화' 원리는 동일(객체가 다를 뿐) |

**재현 조건**: '사진 촬영이 이미 자연스러운 연령대(초등~이십대 초)' + '준비/보고의 객체가 물리적·디지털 사물'일 때. → **10세~28세의 "스스로 증거 남기기" 패턴**으로 일반화 가능.

## O-2. QM-02 (주간 스크린 리뷰) — 재현 가능 페르소나

| 페르소나 | 재현 가능? | 이유 |
|---|---|---|
| P03 중2 남 | ✅ 원본 | — |
| P01/P02 초등 | ✅ 가능 | OS 스크린타임 유아~아동용 제공. 부모가 회의장 역할 |
| P05 고3 | △ 제한 | 사용 시간 자체가 적어 '데이터 리뷰'의 긴급도 낮음(대신 수면·학원 데이터) |
| P06 고2 | ✅ 부분 | 폰+SNS 데이터 → '일정 관리' 데이터로 확장 |
| P15 퇴근 후 | ✅ 변형 | **자기 자신**의 스크린타임을 주간 리뷰(자기 대화) → '회고'로 전환 |

**재현 조건**: '감시-은닉'이 아니라 **'데이터 공동 열람'**이란 장치 자체가 어디든 이식된다.
→ 자료 유형(게임→SNS→업무 시간)만 바뀐다.

## O-8. 재현성에서 뽑은 일반 원칙

1. **QM-04(질문 코드)만 모든 페르소나에 ●** — 대화의 단위는 보편 구조.
2. **부모 축(P07·P08·P09)은 '정보·확인 객체화'(QM-01,03)가 일관 재현** — 부모의 불안은 '모름'이 아니라 '확인 방식'과 관련.
3. **취준 축(P10·P11)은 QM-05가 강하게 재현** — 실패의 반복 노출이 공통 조건.
4. **실패 조건은 '경계 없음'(재택)이나 '조직 정보 주도권 없음'(직장)** — 환경 구조가 개인 행동 설계를 지배.

> 검증 결론: Quiet Move의 핵심은 "사람마다 다른 불만"이 아니라
> **"어느 역할에서나 반복되는 행동 루프의 매개변수"**에 있다. → 페르소나가 달라도 전이가 70~80% 가능.
