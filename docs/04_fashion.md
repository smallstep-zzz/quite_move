## B. Domain Persona — 대표 참가자 3

### P-SH1 이유나 (26) — 무신사/29CM 헤비 쇼퍼 (주인공)
- 정체성/집착: **사이즈 불확실성을 싫어함** — 핏 실패·환불에 대한 후회 회피. 실착사진·옷 리뷰 30~60분 확인. (PERSONA ASSUMPTION)
- 취향: 심플·오버핏·화이트 베이스. 세일 타이밍 예민.
- 지출: 월 20만 내외, 세일 시 40만(과소비 후회 빈번).
- 장치: 위시리스트 스크린샷 수백장, 찜 폴더 분산(무신사·29CM·인스타), 사이즈 계산기 앱 2개.
- 과거 실패(MEMORY): 브랜드별 'S' 사이즈 실패 → 환불 2회 → 이후 **사이즈 표 확인을 최소 2번** 하는 습관(확인 루프).
- 서비스(스펙 §24 '서비스 연결형'): 인스타 발견 → 무신사 검색 → 29CM 비교 → 환불 시 택배 앱 → 검색. **4~6개 앱 순회**.

### P-SH2 김남규 (32) — 워크웨어·되팔이 고려형
- 정체성/집착: 브랜드 아이덴티티와 **리셀 가치 유지**(되팔기 가능 여부)를 동시에 봄.
- 지출: 고가 단일 아이템 월 1회(30~60만). 보유 관리(보관용 가방/습기)에도 신경.
- 회고: 단종 아이템 매입 후 가치 확인 — 2년 걸려 리셀 결정(보유 기간이 길어 마찰).

### P-SH3 박채린 (20) — 지그재그/에이블리 가벼운 구매
- 정체성/집착: 저가+리뷰 사진만으로 빠른 결정. 반복 구매 빈도 높고 단가 낮음.
- 지출: 월 5~8만. 반품률 30%(사이즈 릴스).
- 회고: 반품 귀찮음이 클 때 "애매하면 그냥 받는다" — 감정적 마감.

## C. Behavioral Loop — 반복 구조

```
인스타 발견 → 무신사 검색 → (후기·실착 확인 30~60분) → 29CM 비교
→ 위시/장바구니 → 세일 타이밍 대기 또는 바로 결제
→ 배송 → 실착 → 사이즈 실패(30%) → 환불/재구매 ...
```

반복 지배 루프: **"확인-쇼핑-실패-환불-확인"** — 사이즈 불확실성이 전체 사이클의 마찰을 지배. (CAUSAL INFERENCE)

### 반복 빈도
| 루프 | 횟수/월 | 비고 |
|---|---|---|
| 신상 탐색 | 4~6회/월 | 인스타→앱 이동 |
| 후기·실착 확인 | 구매 당 30~60분 | 사이즈·피팅 검증 |
| 구매 | 2~4건 | — |
| 환불/재구매 | 1건/월 | 사이즈 실패 30% |

## K. Quiet Move Candidates

### KQ-SH-1: "사이즈카드 1장" (1회 기록 → 반복 제거)
기존: 매 구매마다 사이즈표 2번 이상 확인+수십분 후기 스크롤.
변경: **내 신체 치수 1장**(어깨·가슴·기장·허벅지)을 한 번 기록 → 구매 시 사이즈표와 1:1 비교만. 후기는 '핏' 정보만 참고.
- 1회 기록으로 반복 확인 루프를 끊음. (QUIET MOVE, 스펙 §36 '매번 준비를 새로 하는 것')

### KQ-SH-2: "위시 1곳 통합" (위시리스트 단일화)
기존: 인스타+무신사+29CM+스샷 폴더 4곳 분산.
변경: **스크린샷 1폴더**로 물건을 모으고(기존 습관 유지), 폴더를 개봉 단계로. 
- 도구 추가 없이 '스샷'을 '위시리스트'로 재정의. (QUIET MOVE)

### KQ-SH-3: "24시간 위시" (충동 구매 끊기)
기존: 발견 → 후기 30분 → 곧바로 결제.
변경: 24시간 위시 폴더 → 다음 날 재확인 후 구매. 
- '즉시 구매' 인상을 '위시 먼저'로 바꾸는 시작 조건 변경. (QUIET MOVE)

## L. Minimal Product

**KQ-SH-1(사이즈카드) 우선 구현** — 신규 앱 불요, 기록 1장.

| 항목 | 내용 |
|---|---|
| 형태 | **'내 사이즈 카드'(A6 1장) + 휴대폰 메모 1줄** |
| 동작 | 첫 구매 전 얇은 셔츠 상태로 치수 4곳 측정 → 입력 · 구매 시 비교 |
| 비용 | 0원(줄자+메모) |
| 측정 | 구매당 후기 확인 시간, 환불 건수(1건→0.3건), 위시 대행 통과율 |
| 확장 | (2단계) 무신사·29CM 상품페이지에 '내 사이즈카드' 표시 — 사이즈표와 합산 제안 |

> PRODUCT HYPOTHESIS: 사이즈 불확실을 '의류 회사 책임'이 아니라
> **내 측정치 1세트**로 해소하면 후기 스크롤(확인 루프)이 급격히 준다.
