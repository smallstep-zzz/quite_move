# H. Interaction Loops — 사람 사이의 감정 전파·자기강화 고리

> 출력 H | 한 사람의 행동이 다른 사람의 정신 상태를 바꾸고, 다시 되먹임되는 고리를 기록(스펙 §21).
> `【자기강화】` 표시 = 방치 시 갈등이 커지는 고리.

---

## H-1. 가구 A — "확인 고리가 '신뢰 고리'로 뒤집힌 사례"

### H-1-1. 원래 루프 (Baseline, 낙관 반대)

```
[엄마] 준비물 확인(불안 회피)
   ↓
[아이] 수동 + "엄마가 했으니 됐지"
   ↓ (누락 발생)
[엄마] 학교 전화 → 자책 → 확인 강도 +1
   ↓
[아이] 더 의존 → 준비 능력 미성숙 유지
   ↓
[엄마] 사전확인 2회/재확인 1회 ... 【루프 지속, 자기강화】
```

**관측 결과(Day1~3)**: 준비물 누락 2건, 엄마 자책 감정 2회. 한 번의 누락이 엄마 행동을 "더 확인"으로 고정.

### H-1-2. 반전 후 루프 (Intervention)

```
[아이] 가방 사진 업로드(2초×2분)
   ↓
[엄마] "사진 확인"(2초) → 불안 회피 성공 경험
   ↓
[엄마] 확인 강도 자연 감소 → 아이 주체성 관찰
   ↓
[아이] 성취감 → 다음날 더 수행 ...
   【신뢰 루프, 자기강화(긍정)】
```

**Break point**: 매개변수는 "친절함"이 아니라 **"확인의 대상이 누구인가"**. 아이 몫으로 옮기자 루프의 부호가 반전됨.

## H-2. 가구 B — "감시-은닉 루프"와 해제

### H-2-1. 자기강화 루프 (Day2~3 급증)

```
[엄마] "몰래 하는 것" 불안 → 감시(폰 회수/화장실 확인)
   ↓
[아들] "감시당함" → 은닉(이불/화장실) + 방문 닫음
   ↓
[엄마] 은닉 발견 → 불안 ↑ → 감시 강도 ↑
   ↓
[아들] 분노(0.9) → 행동 저항(폰 압수 충돌) ...
   【자기강화, 진폭 상승 예고 — Day3 폭발】
```

**전파의 실체(관측)**: 
- 아들의 "은닉"은 엄마의 "몸으로 확인"을 낳았고,
- 엄마의 "몸으로 확인"(화장실 앞 대기)은 아들의 "신뢰 부재" 해석을 낳음.
- 갈등은 스마트폰이라는 사물이 아니라 **"신뢰 계량기"의 상호 해석**에서 비롯됨.

### H-2-2. 해제 루프 (Day5~7)

```
[엄마] 감시 폐지 대신 "주간 데이터 함께 보기" 제안
   ↓
[아들] "숨길 것이 공유로 바뀜" → 긴장 완화 → 준공개적 사용
   ↓
[엄마] 실수치 확인(게임 14h) → 충격에서 한 걸음 뒤로
   ↓
[아들] 수치가 '비난'이 아닌 '대화'로 처리됨 → 협상
   【루프의 객체가 '행동'에서 '데이터'로 이동 — 자기강화 소실】
```

## H-3. 가구 C — "정보 공급-회피 루프"

```
[엄마] 입시 정보 수집(불안 회피)
   ↓
[아들] 질문 다수 → 회피/거짓 보고
   ↓
[엄마] "내가 모르면 위험" → 수집 강도 ↑
   ↓
[아들] 더 폐쇄 → 수치(숫자=가치) → 거짓 제공 ...
   【자기강화 — 단, 정보량은 증가하고 신뢰량은 감소하는 비대칭】
```

해제: 아들의 **"정보 논의 시점을 정해달라"** 한 문장 → 루프의 주기(빈도)가 잘리며 양방향이 완화.

**특징**: 가구 C 루프는 신호(정보)가 과다해지는 "과다공급형" 루프. 가구 B는 신호가 적어지는 "과소공급형". 가구 A는 객체(확인)가 옮겨지는 "객체 이동형" — **세 유형이 모두 관측되어 루프 분류에 반영**(G-7 참고).

## H-4. P11 — 사회적 루프 (혼자/가족)

### H-4-1. 엄마-딸 루프 (단절형). 【자기강화】

```
[엄마] "취업 소식?" (걱정 표현)
   ↓
[딸] "다 알아서 할게" (회피)
   ↓
[엄마] 더 자주 확인 (불안)
   ↓
[딸] 통화 후 자책(죄책감) → 지원 행동 위축 ... 
   【루프 유지 — 정보 공백이 오히려 양쪽 불안 증폭】
```

### H-4-2. 자기 내부 루프 (취준생의 인지 고리)

```
탈락(사실)
   ↓ 자기평가 정보로 해석
"나는 부족하다"(신념)
   ↓ 다음 지원서 작성 회피 / 과잉 수정
지원 간격 증가 → 시장 잔류 기간 확대
   ↓ 다시 '탈락 잔류'만 누적
```

> Observer 관점: 취준생의 루프는 **외부(가족·경쟁자)보다 내부 해석이 지배**한다. 접근점은 '탈락'의 해석 프레임에 있다.

## H-5. P13/P15 — "퇴근 후 무기력 루프" (스펙 §10 예시 그대로 재현)

```
직장 스트레스(야간 대기)
   ↓
집에서 대화하고 싶지 않음(1인 자취: 폰)
   ↓
스마트폰 멍 시간 증가
   ↓
가족/사람과 대화 감소 (친구 연락 미뤄짐)
   ↓
외로움/방치감 → 자기위로(야식·OTT)
   ↓
취침 지연 → 다음날 피로 → 업무 긴장 ↑
   【하루를 넘어가는 인과 고리 — 자기강화(일주일 주기)】
```

**해제 지점(관측)**: 사회적 루프(H-5)는 "금요일 친구 모임"에 의해 한 주 단위로 끊겼다(에너지 0.2→0.6). 개인 내부 루프의 피로감은 "월요일 첫 일 카드"로 소프트하게 재설정.

## H-6. 루프 유형 분류표 (기록)

| 루프 ID | 유형 | 자기강화 | 해제 개입점 | 관측 결과 |
|---|---|---|---|---|
| L-A1 엄마 확인↔아이 의존 | 객체이동형 | ○ | 확인 주체를 아이로 | 2분 루틴으로 해제 |
| L-B1 감시↔은닉 | 과소공급형 | ○ (강) | 데이터 공동 열람 | 진폭 하락(진행) |
| L-C1 정보공급↔회피 | 과다공급형 | ○ | 논의 시점 재배치 | 강도 1/3 |
| L-O1 엄마 확인↔딸 회피 | 단절형 | ○ | (미해제) 대화 창 | 잔존 |
| L-S1 취준 자기평가 루프 | 내부형 | ○ | 탈락 '프레임 변경' | 잔존(케어 필요) |
| L-F1 퇴근-취침 지연 | 일주기형 | ○ | 사전활동(카드/친구) | 부분 해제 |

**공통 결론**: 모든 자기강화 루프의 해제는 **"감정을 직접 다루는 것"이 아니라 "루프가 도는 매개변수(확인 대상, 데이터 공개 여부, 정보 주기, 해석 프레임)를 바꾸는 것"**으로 일어났다. 이 원리가 섹션 L(Quiet Moves)의 설계 원칙이 된다.
