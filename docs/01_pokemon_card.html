    B. Domain Persona — 대표 참가자 3

    P-PC1 김현우 (28) — 투자 겸 수집가 (주인공)

    • 정체성/집착: "시세가 오르는 것을 놓치는 것" 을 가장 싫어함. 희귀 카드 급상승 문턱을 감지하는 게 자신의 능력이라고 믿음. (PERSONA ASSUMPTION)
    • 숙련도: 중상. 개봉 영상 시청·시세 표 추적 2년. 최고가 카드 소유 경험 없음.
    • 목표: 보유 카드로 사고파는 리셀 수익 + 소장 가치 동시 추구.
    • 장비/지출: 카드 앨범 3권, 미개봉 박스 2개 보관, 월 지출 평균 35만원(저장 후 위험 부담).
    • 시간 사용: 하루 40분 시세 확인(퇴근 후), 주말 개봉 스트리밍 2회.
    • 서비스: 크림, 번개장터, 카페("포켓몬카드 시세"), 유튜브 개봉 채널.
    • 과거 실패(MEMORY): 6개월 전 '급등 직전 매도' 후회 — 이후 시세 확인 빈도가 2배로 증가 (손실 기억의 재활성화).
    • 잘못된 결론(CAUSAL INFERENCE 후보): "많이 확인할수록 판단이 정확해진다" — 실제로는 확인이 늘어나도 시세는 유동적.

    P-PC2 박서준 (11) — 초등생 함께 수집가

    • 정체성/집착: 카드를 신분증처럼 가방·지갑에 넣고 다니는 습관. "나만의 치맛 카드"를 공개하는 게 기쁨.
    • 지출: 용돈 1만~2만원/월 + 어른 선물. (PERSONA ASSUMPTION)
    • 과거 실패(MEMORY): 운동장에서 분실한 카드 — 재구매 후 "절대 떨어뜨리지 않아" 반복 다짐.
    • 가족 관계: 엄마가 구매를 함께하며 감정적 소비 통제자 역할. (간접 활동)

    P-PC3 이연수 (34) — 오랜 수집가 (향수 · 보관)

    • 정체성/집착: 90년대 1세대 카드의 습기·페이딩·모서리 손상 방어. 감정 등급 의뢰에 거래 비용.
    • 목표: 희귀도 낮아도 '기억 카드'를 전시·보관. 수집 ≠ 투자라는 자기 방어적 원칙.
    • 행동: 슬리브/탑로더/바인더 관리, 월 1회 보관 점검, 기념일마다 카드를 꺼내봄(REFLECTION 유발).

    C. Behavioral Loop — 분야의 반복 구조

    시세 확인(기본) → 상승 카드 발견 → 가격 비교(크림↔번개↔카페)
→ 구매 결정 헌간(오픈런/박스/싱글) → 개봉 → 시세 즉시 재확인
→ 중복/대박 결과 → 보관 or 리셀 등록 → 또 시세 확인 ...

    이 루프는 기본 3회/일로 도는 구조. (스펙 §8) — 수집 분야는 "확인→구매→결과→확인"이 재사용 여부와 무관하게 계속 반복된다.

    반복 빈도 (주간 추정, P-PC1 기준)

    루프 횟수/주 감정 강도
    시세 재확인 3~5회 높음(불안)
    상대 비교/가격 확인 2~3회 중간
    개봉 및 결과 확인 1~2회 최고(기대+후회)
    중복 정리 0.2회(방치) 낮음→누적 스트레스
    리셀 등록/문의 0.5회 중간(거래 불안)

    E. Memory Timeline — 기억의 누적·재활성화

    • 2019 첫 대박: 피카츄 Vmax 홀로그램 — 이후 "개봉은 저축이다"라는 비합리적 신념. (MEMORY)
    • 2026.3 급등 매도 후회: 손실 기억이 시세 확인 습관을 강화. (MEMORY → CAUSAL INFERENCE)
    • 정품 문의 실패: 커뮤니티에서 가품 판매자와 거래 중단한 경험 → 신뢰 판별 확인 절차 증가(3단계: 사진→검수→태그). (MEMORY)
    • 기억이 재활성화되는 순간: 신제품 발매 주간, 리셀 문의가 들어온 순간, 연말 정산. (MEMORY)

    H. Abstraction / Generalization — 사람이 뽑은 (부정확한) 패턴

    • "많이 확인할수록 판단이 정확하다" (시세 확인 빈도 늘릴수록 불안 해소된다고 착각) — 잘못된 원인 추론 (스펙 §18)
    • "개봉은 저축이다" — 대박 경험의 과잉 일반화
    • "희귀 카드는 언젠가 오른다" — 무한 성장 확신

    각 패턴은 부적응적이며, 여기서 Quiet Move가 개입할 지점이 된다. (CAUSAL INFERENCE)

    I. Turning Points — 행동·사고가 바뀐 순간

    • TP-PC-1: 3월 급등 카드 조기 매도 후회 → 시세 확인 2배 증가. (사건 → 해석 → 습관 강화)
    • TP-PC-2: 급락 주간에 개봉 멈춤 2주 — "그냥 카드에 신경 끄자" → 보유 목표로 전환 잠깐 성공(1개월 후 복귀).
    • TP-PC-3 (near-miss): 리셀 가품 신고 후 '거래 3단계 확인' 루틴 생성 — 신뢰 판별 신뢰 증가.

    최대 전환점은 사실상 TP-PC-1 — 그 순간부터 "확인하지 않음 = 손실" 프레임이 고정됨. (CAUSAL INFERENCE)

    K. Quiet Move Candidates — 작은 개입 후보

    KQ-PC-1: "개봉 앵커 1장" (개봉 직후 기준점)

    기존: 개봉 → 시세 3~5번 재확인(후회·불안) → 결정. 변경: 개봉 직후 시세 스크린샷 1장 + 1문장(팩명·기분) 저장 → 그 시점이 '내 결정 기준점'이 되어 이후 재확인을 줄임. - 행동 변화: 1장 추가(10초) / 제거: 재확인 3~5회 → 1~2회. - 왜 작은가: 개봉 영상 촬영·스크린샷은 이미 하고 있는 습관의 연장 (QUIET MOVE)

    KQ-PC-2: "중복 정리 주 1회 슬롯" (보이지 않는 부채 처리)

    기존: 중복이 쌓임 → 바인더 넘침 → 정리 통에 방치. 변경: 매주 일요일 30분만 '트레이드/판매 등록' 시간으로 고정. 그 외에는 등록 금지(재배치). - 중복 정리는 '즐거움'이 아니라 '숙제'이므로, 전환 의식을 만들어 마찰을 낮춘다. (QUIET MOVE)

    KQ-PC-3: "외출 카드 1장 규칙" (P-PC2 아동용)

    기존: 지갑·주머니에 카드 휴대 → 분실·굽힘 위험 지속. 변경: 외출 시엔 탑로더에 꽂은 1장만 + "돌아오면 제자리" 규칙. - 확인 주체를 '방에 놔두기' 의식으로 바꿈(카드는 여전히 가지고 다님). (QUIET MOVE)

    L. Minimal Product — 가장 작은 제품 형태

    KQ-PC-1(앵커 1장)을 최우선으로 구현 — 종이/앱 0원 부하.
